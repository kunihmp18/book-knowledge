## 2. 著者の主張（出典付き）

### 給与の減額 — 制度がなければ実質できない

【著者】**「これを会社側で一方的に減額できないのが原則です」**。同意を得る場合でも
**「その同意は労働者の自由意思に基づく明確なものであることを必要とし、黙示の合意の場合は
その成立や有効性は容易には認められないため、書面で同意をもらうことは最低限必要です」** [p.354]。

【著者】人事権の裁量で減額するには、**就業規則で職務・職能に対応した賃金制度を整備**し、
その制度にのっとって評価を行う必要がある。**「客観的な基準なしに、特定の人を狙い撃ちして、
『経営陣からの評価が悪いから給与を減額する』などという措置は権利濫用として認められません」** [p.355]。

【著者】スタートアップの実情への指摘が具体的。**「この賃金制度が整備されていない例も多く、
会社による定期的な評価さえ行っていないことも多いため、いざ『パフォーマンスが悪いから
給与を減額したい』となっても、適法にこれを行うことが難しいのが実情です」** [p.355]。

【著者】最低限やるべきこととして、**「役職手当」を設けて昇格・降格に伴い手当の有無を
変更できるようにする**、**年1〜2回は経営陣による面接を行い客観的な人事考査項目に従って
評価する**、を挙げている。いずれも**就業規則や給与規程にあらかじめ規定しておくことが前提** [p.355]。

【著者】懲戒処分としての「減給」は別物で、労働基準法91条により
**1回の額は平均賃金の1日分の半額まで、総額は一賃金支払期の賃金総額の10分の1まで**。
月給20万円なら1回5,000円程度で、著者は**「意外と少ないことが分かります」**と [p.356]。

### 解雇 — 退職勧奨のほうが望ましい

【著者】**「解雇の適法性の判断は厳しくなされるため、一般的には退職勧奨によって従業員に
辞職してもらうほうが望ましいです」** [p.357]。

【著者】能力不足を理由とする解雇は**「判例実務上認められるためのハードルはかなり高く、
安易にこの点を根拠に解雇をするのはリスクが高い」** [p.359]。

【著者】懲戒処分は**段階を踏むこと**が重要。軽微な違反にはまず戒告等で対応し、繰り返されたら
**「黙認することなく、その都度適正な懲戒処分を行います」**。
**「このように、段階を踏んでおくことで、最終的に将来の解雇の相当性が是認されやすくなります」** [p.360]。

【著者】逆の注意もある。**「一度不問に付したり、軽微な処分をしておきながら、同一の事案に
ついて事後的に新たに処分を課すことは許されません」** [p.360]。

【著者】退職勧奨の実務的な作法。**面談は2〜3人程度の複数で対応**（1人だと水掛け論、
多すぎると威圧的）、過度に長時間拘束しない、**「あくまで説得の範囲を出ないよう心がける」** [p.361]。

【著者】無効になった場合の重さ。**「それまでの期間の給与とその遅延損害金を遡って
支払わなければならない」** [p.361]。

### 労働時間 — 完全に逃れられる制度はない

【著者】未払い残業代は**IPO・M&Aの審査項目**。賃金請求権の消滅時効は5年
（当分の間は経過措置で3年）[p.348]。

【著者】労働時間の把握方法は、⒤使用者が自ら現認 ⒤⒤タイムカード・ICカード・PCの
使用時間記録等の**客観的な記録**が原則。**⒤⒤⒤自己申告制はあくまで例外的な方法**で、
一定の措置を講じる必要がある [p.348–349]。

【著者】各制度の限界 [p.351–353]。

| 制度 | 効果 | 限界 |
|---|---|---|
| フレックスタイム制 | 1カ月の法定労働時間内なら時間外にならない | 総労働時間を超えれば残業代は発生 |
| 裁量労働制 | 基本的に残業代が発生しない | **休日・深夜の割増賃金は発生**。2024年4月以降は本人同意等の手続が厳格化 |
| 管理監督者 | 時間外・休日の割増賃金が不要 | **年次有給休暇・深夜労働の割増は適用除外にならない**。名称でなく実態で判断 |
| みなし残業代制 | 一定範囲の残業代を固定で支払える | **超過分は差額を払う必要**。結局労働時間の把握は必要 |

【著者】みなし残業代制の有効要件は㈠明確区分性 ㈡対価性 ㈢差額支払の合意 [p.353]。
時間数は**三六協定の範囲（通常は1カ月45時間）に限定しておいたほうが安全** [p.354]。

### 競業避止 — 入社時に定めておく

【著者】退職後の競業避止義務の合理性は、①競業制限する必要性 ②制限の範囲（期間・場所・職種）
③在職時の労働者の地位 ④制限に対する代償の有無 を総合考慮して判断される
（フォセコ・ジャパン事件・奈良地判昭45.10.23）[p.363]。

【著者】**入社時に定めるべき**という実務的な理由が明快。
**「円満退職であれば問題は少ないですが、残念ながら退職時に揉めたケースでは、揉めている
従業員から誓約書や退職合意書を取得するのは困難だからです」** [p.363–364]。

【著者】秘密保持義務も、**対象が過度に広範だと公序良俗違反で無効**とされる可能性があるため、
**対象となる秘密情報はできる限り特定**する [p.364]。

【著者】そもそも法的手段だけに頼るべきでないという指摘。
**「会社が外部に出したくない情報については、アクセスできる人を限定する等して、
なるべく外部に持ち出せないようにするとともに、仮に外部に持ち出されてしまった場合には
誰が持ち出したかを特定しやすくする等の事前の対策が重要です」** [p.365]。

### フリーランス保護法 — 2024年11月1日施行

【著者】適用範囲が広い。**発注事業者がフリーランス（①従業員を使用しない個人、
②代表者以外に役員がなく従業員を使用しない法人）に業務委託をする場合に広く適用** [p.373]。
下請法のような資本金要件がない。

【著者】主な義務 [p.374–378]。

| 条 | 義務 | 要点 |
|---|---|---|
| 3条 | 取引条件の明示 | 8項目を書面または電磁的方法で**直ちに**明示 |
| 4条 | 期日における報酬支払 | **受領日から60日以内**。起算日は検査完了時点ではなく**受け取った日** |
| 5条 | 7つの禁止行為 | 受領拒否・報酬減額・返品・買いたたき・購入利用強制・不当な利益提供要請・不当な変更/やり直し |
| 12条 | 募集情報の的確表示 | 虚偽・誤解を生じさせる表示の禁止 |
| 13条 | 育児介護等との両立配慮 | 6カ月以上の委託は義務、未満は努力義務 |
| 14条 | ハラスメント対策の体制整備 | **従業員向けと同様の措置をフリーランスにも広げる** |
| 16条 | 中途解除等の事前予告 | 6カ月以上の契約は**30日前までに予告**、理由開示請求に応じる |

【著者】契約不適合責任の期間にも影響する。7）の禁止行為との関係で、
**受領後1年を経過した場合の変更・やり直し要請は禁止**と解されており、
**フリーランスが契約不適合責任を負う期間もそれを超えないようにしたほうがよい** [p.376]。

【著者】**偽装請負**の判断基準を具体的に列挙している（使用従属性5項目＋補強要素4項目）。
著者は**「下記の判断基準等をもとにチェックリストを作成するなどして、個別の依頼が
『偽装請負』に該当しないように確認および運用したほうが安全です」**と勧めている [p.379]。

### 採用インセンティブの落とし穴

【著者】**社員紹介制度**の紹介料は、職業安定法40条により
**「賃金、給料その他これらに準ずるもの」として支払う必要**がある。就業規則等に業務に対する
賃金である旨を明記し、金額・支払条件・支払時期も規定しておく [p.381]。
**職業紹介事業者に支払う成功報酬のような高額にはしないほうが安全** [p.381]。

【著者】**現物支給は不可**。労働基準法24条1項が「賃金は、通貨で」と定めるため、
オフィス雑貨等の現物を渡すと職業安定法40条違反と判断されるリスクがある [p.381]。

【著者】**サイニングボーナスの返還合意は無効の可能性**。一定期間内に自己都合退職した場合に
全額返還させる合意は、労働基準法16条（賠償予定の禁止）・5条（強制労働の禁止）に違反しうる。
**これらの規定違反には刑事罰もある**（労働基準法117条、119条）[p.380, p.382]。

【著者】回避策として、**入社時に直ちに支払わず一定期間就労した場合にのみ支払う**、
または**一定期間後に分割して支払う**形にすることを挙げている [p.383]。

## 3. 取り返しがつかない論点（読む目的に照らして抽出）

| 論点 | なぜ取り返しがつかないか | 出典 |
|---|---|---|
| **賃金制度・評価制度の不在** | 制度がないと、後から「評価が悪いので減給」ができない。**制度は遡って作れない** | p.355 |
| **懲戒の段階を踏まなかった過去** | 一度不問に付した事案に、後から処分は課せない。解雇の相当性も積み上がらない | p.360 |
| **退職後の競業避止を入社時に定めていない** | 揉めた退職者から誓約書は取れない | p.363–364 |
| **秘密情報のアクセス制限** | 持ち出された後に「制限していた」とは言えない。事前の設計がすべて | p.365 |
| **サイニングボーナスの支払い方** | 一括で払ってしまえば返還を求められない可能性が高い。**分割・後払いは設計時にしか選べない** | p.382–383 |
| **フリーランス契約の条件明示** | 委託した時点で「直ちに」明示する義務。後から書面を作っても遡らない | p.374 |
| **未払い残業代** | 消滅時効は5年（当分は3年）。**過去分がIPO・M&Aで必ず出てくる** | p.348 |

## 5. open_questions（VoC／Patchinとの前提差）

1. **VoCの人員は誰の従業員か。** 親会社の従業員が出向・兼務している場合、就業規則も
   賃金制度も親会社のもの。本章の「自社で整備する」前提が当てはまらない。
2. **外部エンジニアへの委託主体は誰か。** 親会社名義ならフリーランス保護法の
   「発注事業者」は親会社。ただし**フリーランス保護法には資本金要件がない**ので、
   VoC名義でも適用される [p.373]。下請法とは適用範囲が違う点に注意。
3. **社内ベンチャーの人員に競業避止を課せるか。** 親会社の就業規則が上位にあるため、
   VoC独自に定められるかは不明。
4. **PoCの記録（打ち合わせの録音・分析）は労働時間管理と交差しないか。**
   `docs/poc_plan_voc.md` の対象は「VOC事務局の打ち合わせ」。**業務中の記録であり、
   従業員が対象**。パワハラ指針の「個の侵害」に**労働者を職場外でも継続的に監視すること**が
   挙げられている [p.367] のは、Patchinの「監視しない」という設計判断と同じ問題圏。
   本書は労務管理の文脈で書いており、製品設計の文脈ではないが、**論点として接続する**。

## 6. この範囲の限界

【評】

- **フリーランス保護法は2024年11月施行で、運用実績が浅い。** 本書も条文と指針の紹介が
  中心で、実際にどう摘発・是正されるかの蓄積はまだない
- 賃金・評価制度の「作り方」は薄い。**何が必要かは書かれているが、どう作るかは書かれていない**
- ハラスメントの記述は**指針の引き写しが中心**。スタートアップ固有の難しさ
  （少人数で相談窓口をどう作るか、経営者本人が当事者の場合など）には踏み込んでいない
- 第2版の基準時（2025年4月）以降の改正は未反映
