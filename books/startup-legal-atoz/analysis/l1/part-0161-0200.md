## 1. この範囲の骨格

**「同じことを定款でやるか、契約でやるか」が繰り返し問われる。**

前バッチ（p.105–144）が投資契約の各条項を扱ったのに対し、この範囲は
**同じ内容を種類株式（＝定款）として設計する場合との比較**が主題になっている。
著者は4つの違いを明示している [p.150–151]。

| | 種類株式（定款） | 投資契約 |
|---|---|---|
| 定められる事項 | 会社法上の限定あり | 基本的に制限なし |
| 誰が権利を持つか | 同種の株主に**平等に** | **契約当事者だけ** |
| 誰を拘束できるか | 同種の株主を平等に拘束 | 当事者以外は拘束できない |
| **違反したら** | **行為が無効** | 会社法上は有効／契約違反にとどまる |

【著者】**「違反行為を無効としたい重要事項については、種類株式の内容として定款に定めることを
検討したほうがよい」** [p.151]。

【評】ただし著者は同時に**定款側の副作用**を繰り返し指摘している（後記4）。
「強いほうを選べばよい」という単純な話ではないのが、この範囲の読みどころ。

## 2. 著者の主張（出典付き）

### 種類株式の発行目的は11個ある。目的を決めずに設計すると壊れる

【著者】**「かかる目的のためだけに可能な限り投資家（株主）に有利な規定を盛り込むという
方針で設計してしまうと、種類株式の内容が必要以上に複雑になり、その設計に過剰な
リーガルコストがかかるばかりでなく、投資後の運用も困難となるうえ、次の資金調達ラウンドの
支障となるおそれもあります」** [p.146]。

【著者】挙げられている目的（要約）[p.146–150]：①みなし清算条項の導入 ②清算時のリスクヘッジ
③希薄化防止対策 ④投資資金の回収 ⑤特定事項についての拒否権 ⑥役員選任権の確保
⑦剰余金配当時の優先 ⑧ストックオプションの行使価額との関係性 ⑨投資直後の詐欺的解散の防止
⑩高株価の理由付け ⑪経営悪化時の経営権取得

### ⑨投資直後の詐欺的解散 — 優先株が守っているもの

【著者】経営陣が1株1万円で1,000株（1,000万円）出資して設立、投資家が1株10万円で500株
（5,000万円）を投資。キャッシュ6,000万円が残っている状態で、経営陣が3分の2以上の持株比率を
使って**解散決議**をすると [p.149]：

| | 分配額 | 損益 |
|---|---|---|
| 経営陣 | 4,000万円 | **3,000万円の利益** |
| 投資家 | 2,000万円 | **3,000万円の損失** |

【著者】「1株当たり10万円の優先残余財産分配権を定めた種類株式で投資をすれば、
このようなリスクを避けることができます」[p.149]。

【評】優先株式を「投資家がとりすぎている仕組み」と見ると交渉が対立に寄る。
**この例は「なぜ普通株式では投資家が投資できないか」を説明している**。理解しておくと、
どこまで譲るかの判断軸になる。

### ⑧優先株のほうが SO の行使価額を低く抑えられる

【著者】税制適格ストックオプションの権利行使価額は普通株式の時価以上でなければならないが、
取引相場のない株式は**特例方式（純資産価額方式）**で算定でき、その際
**優先株式に対する優先的な残余財産分配の対象となる金額を控除**したうえで株式数で割る [p.148]。

【著者】**「スタートアップの財務状況を踏まえると、上記の計算により算出される普通株式1株
当たりの純資産価額がマイナスになることも多く、この場合は、権利行使価額を1円以上の任意の
金額に設定すれば税制適格の要件を充足し得る」** [p.148]。

【評】優先株ファイナンスの**副次的なメリット**。従業員インセンティブの設計に直結する。

### 優先的残余財産分配の相場は「1倍参加型」

【著者】**「実務において最も多いのは、優先的に分配を受ける残余財産の金額を払込金額の1倍に
し、かつ、参加型とする設計（1倍参加型）であるといえます」** [p.156]。

【著者】払込金額の「X倍」は「日本の場合は『1倍』が大半ですが、『1.5倍』等にするケースも
あります」[p.155 脚注1]。累積未払配当金を優先分配額に加算する設計は**「稀」**[p.155]。

【著者】ただし変化の兆しがある。規模の大きな M&A で参加型の分配を得るのが公平かという
問題意識と、米国では非参加型が一般的という傾向から、**「日本においても、非参加型の設計を
採用するケースも見られるようになってきました。今後の実務の動向に注目されます」** [p.156]。

### 累積型の優先配当は IPO の支障になりうる

【著者】累積型にすると優先配当すべき金額が年度ごとに累積する。株式公開時点で優先株式が
一部残存し、未払いの累積額が多額になっていると「株式公開後普通株式への配当が事実上困難と
なり…**このような累積型の優先株式の存在が株式公開の支障となる可能性もあります**」[p.153]。

【著者】投資家側の狙いは配当そのものではない。**「この累積した未払い配当の金額を、
優先的な残余財産分配金額や金銭を対価とする取得請求権を行使した場合の金銭対価の金額に
加算することで、最終的に現金回収する場合の利息相当分として上乗せする意味を重視する
場合もあります」** [p.153]。さらにみなし清算の対価も増える。

【評】**「配当の話」に見えて実は「Exit 時の取り分の話」**。名前で判断すると論点を見落とす。

### 希薄化防止の3段階 — 創業者から見た厳しさが違う

【著者】ダウンラウンド時に優先株の取得価額を調整する方式 [p.158]：

| 方式 | 内容 | 既存株主から見て |
|---|---|---|
| フルラチェット | 低額の発行価額を**そのまま**調整後取得価額に。発行株式数を考慮しない | **厳しい** |
| 加重平均・ナローベース | 顕在株式のみで計算 | マイルド |
| 加重平均・ブロードベース | 潜在株式も含めて計算 | **よりマイルド** |

【著者】**「普通株式を保有する起業家を含む既存株主にとっては、調整がより緩やかになる
ブロードベースのほうが一般的に有利となります」** [p.158]。
「通常の案件では、加重平均方式が使われることが一般的です」[p.159]。

【著者】フルラチェットが使われるのは、バリュエーションが高くなりすぎてダウンラウンドの
リスクが高い案件や、バイオ銘柄のように**ダウンラウンドでも調達しないと生き残れない**企業 [p.159]。

### 取得条項（強制転換）— 入れるか否かではなく「戻せるか」

【著者】IPO 前に優先株を全部普通株に転換するよう主幹事証券から指導されるのが一般的 [p.160]。
だが優先株主が拒否する可能性があるので、会社側から強制転換できる取得条項が要る [p.161]。

【著者】投資家側は嫌がる。**「優先株式を普通株式に強制的に転換されたにもかかわらず、
結局株式公開がスケジュールどおりに実現しなかった場合のリスクを懸念せざるを得ません。
そこで…投資家側としては取得請求権を自発的に行使して対応するから取得条項は入れる必要が
ない旨の主張をするケースが多くあります」** [p.161–162]。

【著者】著者の出す案は**条項を入れたうえで戻せるようにする** — 株主間契約で
「優先株式が普通株式に強制転換された後一定期間内に会社の株式公開が達成されなかった場合には、
会社は元の優先株式に戻す転換の手続を行い、株主間契約の全当事者はそれに協力をする旨を
定めることが考えられます」[p.162]。

【評】ドラッグ・アロング・ライトの「時期と金額を織り込む」[p.119] と同じ型。
**この本の交渉論は一貫して「ゼロか100かを避け、条件で刻む」**。

### 手続に時間がかかる — 取得条項の発動

【著者】取得条項の発動には**株主への2週間前の通知または公告**が必要。株券発行会社なら
原則として**1カ月前までの株券提供の公告および通知**も要る [p.161 脚注1]。

【著者】**「株券発行会社の場合には、上場申請前に取得条項に基づき全ての優先株式を普通株式に
転換させるためには、上場申請の1カ月以上前に取得条項を発動できる事由が発生している
必要があります」** [p.161 脚注1]。

### 外為法 — スケジュールが動く

【著者】海外ファンド等から出資を受ける場合、投資家側に事前届出義務が生じることがあり、
**届出後の待期期間（法令上30日、実務上は通常2週間程度に短縮）が満了しないと株式を取得
できない** [p.176]。

【著者】引っかかりやすい点 [p.175–177]：

- **日本法人・日本籍ファンドでも「外国投資家」になりうる**。外国の非居住者・外国法人の
  議決権比率が50%以上、業務執行組合員が外国法人、出資額の半数以上を外国籍ファンドが拠出。
  **「スタートアップ側としては、投資家に関する公開情報等から判断するのが難しい場合がある」**
- **非上場企業は1株取得するだけでも「対内直接投資等」に該当**。少額出資のエンジェル投資家が
  非居住者でも規制対象
- **「近時の改正により、インターネットサービス等でアプリ開発を行うような企業に関しては、
  幅広く事前届出対象業種に該当する形となってしまいました」**
- **J-KISS は取得時点では非該当**。新株予約権の行使による株式取得のタイミングで判定
- **役員派遣も「対内直接投資等」に該当する**。「外為法の規制が問題になるのは、
  投資実行時点だけではないことに留意が必要です」

### 株式 vs ストックオプション — 原則は SO

【著者】**「原則としてストックオプションを使うこととし、例外的に創業メンバーとほぼ同様の
地位を占めるような幹部候補を雇う場合などの場合のみに株式を使うのがよい」** [p.180]。

【著者】株式の一番の問題は退職後。**「その方が退職した場合でも、一方的に権利を消滅させる
ことができず、株主として残り続けてしまう点です」** [p.182]。会社が買い取ろうにも自己株式
取得は分配可能額の財源規制があり、**「これに違反して買い取ると『会社の計算で不正に株式を
取得』したとして刑事罰の対象となることもある」**（会社法963条5項1号）[p.182]。

【著者】**「実際に、株式を保有してもらった従業員が退職し、その後も株主として残ったために
トラブルとなるケースは非常に多くみられます」** [p.182]。具体的なトラブルがなくても、
既存投資家からの評価、他の役職員のモチベーション、「全株主の同意」が要る場面での
**「連絡が取りづらい株主」**が問題になる [p.182]。

【著者】SO なら「退職したら権利を無償で会社が取得できる」と規定しておくのが通常で、
**そのような規定があれば退職後に一方的に権利を消滅させられる** [p.183]。

## 3. 取り返しがつかない論点

| 論点 | いつ手遅れになるか | 出典 |
|---|---|---|
| **SO の「退職したら消滅」規定** | 付与時の設計にしか入れられない。付与後の内容変更は株主総会の承認＋全権利者の同意 | p.183（変更要件は p.191） |
| **従業員に株式を渡してしまう** | 退職しても一方的に消滅させられない。自己株式取得は財源規制があり、**違反すれば刑事罰** | p.182 |
| **希薄化防止をフルラチェットで受け入れる** | ダウンラウンド時に発行株式数を考慮せず調整され、既存株主の希薄化が大きい | p.158–159 |
| **累積型の優先配当** | 未払額が累積し、**IPO の支障になりうる**。累積した事実は消せない | p.153 |
| **取得条項を入れそこねる** | IPO 前に優先株を全部転換できず、上場が進まない。後から入れるには**定款変更＋種類株主総会** | p.160–161 |
| **取得条項の発動が上場申請に間に合わない** | 株券発行会社は**1カ月以上前**に発動事由が発生している必要がある | p.161 脚注1 |
| **外為法の事前届出を見落とす** | 待期期間（実務上2週間程度）が満了するまで株式を取得できず、**調達スケジュールが動く** | p.176 |
| **端数処理の規定が不明確** | 転換後の普通株式数が確定できず、**上場関係書類の記載で問題が生じる** | p.162 |

## 4. 判断の分かれ目

### 定款（種類株式）と投資契約、どちらに書くか

【著者】定款側の副作用が3つ挙げられている [p.165–166]。

1. **意思決定が遅くなる**。細かい事項を種類株主総会決議事項にすると、本来取締役会で
   機動的に決めるべきことに逐一種類株主総会が要る
2. **持株比率の低い投資家にも権利を与えてしまう**。投資契約なら自己のみが拒否権を持てる
3. **その後の持株比率低下で実質的に拒否権を失う**。ラウンドを重ねると種類株主総会での
   過半数を割りうる。投資契約なら「契約を修正しない限りこのような事態は生じません」

【著者】さらに**「種類株主総会決議事項の定め方が曖昧であると…不要と判断して進めた事項が、
後にやはり必要であったとなると、定款違反として無効となる可能性もあります」** [p.165–166]。

【著者】そして投資契約も弱くはない。**「投資契約の違反については、経営者による株式買取義務
などのペナルティがあり、投資家の拒否権を明確に無視して強行する事態は想定しにくく、
投資契約の拘束力は必ずしも弱いとはいえません」** [p.165]。

【評】前バッチで見た「定款なら無効にできる」という強さは本当だが、
**強さの代償が3つある**。ここは単純な優劣ではない。

### 拒否権を「株主X個人に」与えるか「種類株主総会の決議事項」にするか

【著者】投資契約で株主Xに拒否権を定めれば、同じ種類の株式を持つ他の株主に拒否権はない。
一方、種類株主総会の決議事項にすると**他の株主も平等に1株1議決権**を持つため、
**「仮に株主Xの議決権数が当該種類株主総会において一定数に満たない場合には、
株主Xのみで拒否権を発動できないことになります」** [p.150]。

### 役員選任権を種類株式で定めるか

【著者】定めると副作用がある [p.167]。①持株比率の低い株主も取締役候補の適否の意思決定に
参加する ②持株比率低下で選任権を失いうる ③投資契約なら「いざというときまで指名権を
行使しない」運用が可能だが、種類株式だと他の優先株主との関係で**柔軟な運用ができるか疑問**。

【著者】さらに**「この役員選任権を定めた場合には、取締役等の選任を…種類株主総会決議事項と
することができず、普通株主による取締役の選任について会社法上の拒否権を定めることが
できなくなる」** [p.167]。

## 5. open_questions（VoC／Patchinとの前提差）

1. **VoC で「種類株式か契約か」の対比は成立するか。** 親会社100%出資なら種類株式を作る
   意味は薄いが、**外部が入る瞬間に一気に効いてくる**。どの時点で検討を始めるべきかは不明。
2. **VoC の人員に SO を出せるか。** 出向者や親会社従業員が対象の場合、
   税制適格の「取締役または従業員」要件[p.191で既読]をどう満たすか。本書は自社雇用が前提。
3. **親会社が「外国投資家」に該当する可能性はないか。** 日本法人でも外国の非居住者・
   外国法人の議決権比率が50%以上なら該当しうる [p.175]。**役員派遣も対内直接投資等**なので、
   資本関係だけでなく人の派遣でも問題になる。
4. **Patchin が将来外部調達するとき、希薄化防止をブロードベースにできるか。**
   相手次第だが、**「通常の案件では加重平均方式が一般的」**[p.159] という相場は交渉材料になる。

## 6. この範囲の限界

【評】

- **技術的な記述が中心で、判断の軸が薄い箇所がある。** 端数処理（p.162–163）や現物出資規制の
  例外要件（p.172）は手続の説明であり、「どう決めるか」は書かれていない
- **相場が示されているのは優先残余財産分配（1倍参加型）と希薄化防止（加重平均）だけ。**
  他の条件（バリュエーションキャップの水準、ディスカウントレートの相場など）は伏字のまま
- **「今後の実務の動向に注目されます」[p.156] のように、書いた時点で流動的な論点がある。**
  非参加型への移行はまさに進行中で、第2版（2025年4月）の記述はすぐ古くなりうる
- 外為法のコラムは**規制の概要**にとどまる。実際に届出が要るかの判定（業種の該当性）は
  本書では判断できない
- 取得条項付株式の端数処理について著者自身が「**234条の適用を回避できるかは不明**」
  「脱法と解される可能性も否定できません」[p.163] と書いている。**未解決の論点が残っている**
