# L6 — VoC（社内ベンチャー）：何を今決め、誰に何を聞くか

## この文書の位置づけ

**本書は独立資本のスタートアップを前提に書かれている**（L4 §8）。
VoC は博報堂の社内ベンチャープログラムであり、**株式がなく、出口がなく、
就業規則も稟議規程も親会社のもの**という前提の違いがある。

そのため本書の記述は「そのまま使えない」ものが多い。
**だが使えないことと、関係ないことは違う。** この文書は、
**前提が崩れている箇所ごとに、代わりに何を確認するか**を並べる。

### 前提となる状況（要確認）

`docs/STATE.md`（最終更新 **2026-07-22**）による。**3週間以上経っている。使う前に読み直すこと。**

- 投資委員会は通過済み。8月中旬に稟議必要資料、8月末に水島会長・西山社長・江花役員へ報告
- 9月：VoC取締役会 → HC事前報告 → HC取締役会
- PoC は VOC事務局・社内情報のみで小さく開始（他部署を巻き込む正式手続きは約半年）
- **「一回ドアノックしてNGが出たら覆らない」** → 申請より先に相談チャネル

## 1. 最優先 — 職務発明の帰属

**本書 QVII-3 の設問は、Patchin の状況とほぼ同じ文面である。**

> 当社は創業社長が発明した特許を基礎とした事業を展開しており、今後も社内で関連する特許が
> 発生する可能性がありますが、役員や従業員が発明した特許は会社に帰属するのでしょうか。 [p.314]

**本書の答えが重い：**

- 特許法35条により、職務発明は「**何もせず放っておくと、発明者である従業員等に権利が帰属し、
  会社は通常実施権を取得するのみ**」[p.315]
- 会社に帰属させるには「**あらかじめ**、社内規程や雇用契約などで定めた」ことが必要 [p.315]
- **「職務発明は当然に会社に帰属すると勘違いされていることが多い」**と、第X章でも
  改めて警告されている [p.412]

**VoC の問題はここから先。** 本書は「自社で職務発明規程を作る」前提で書かれているが、
**発明者が親会社の従業員なら、適用されるのは親会社の職務発明規程である可能性がある。**
その場合、**特許は博報堂に帰属していることになる。**

### 確認すること（今週）

| # | 確認 | どこを見るか |
|---|---|---|
| 1-1 | 特許の**出願人は誰の名義か** | 出願書類 |
| 1-2 | **発明者の所属**は発明時点でどこだったか | 雇用の履歴 |
| 1-3 | 博報堂に**職務発明規程はあるか。あるなら Patchin の発明が「職務に属する発明」に当たるか** | 社内規程（人事部・法務部） |
| 1-4 | 将来 Patchin が法人化したとき、**特許をどう移すことになっているか**の合意はあるか | VoC の制度設計文書、投資委員会の資料 |

**なぜ最優先か**：これは L5 の **【A】仕組みを作る前にしか作れない** に当たる。
法人化してから「実は親会社のものでした」となると、**移転の交渉から始まる**。
交渉相手は親会社であり、こちらに交渉力はない。
そして本書は、DD でも IPO審査でも**必ず見られる項目**だと繰り返している [p.398, p.412]。

**8月末の報告会・9月の取締役会は、この点を確認して臨む場面である。**
「特許は誰のものか」を役員に聞かれて答えられないのは、投資委員会通過後の状態としてまずい。

## 2. 前提が崩れている箇所と、代わりに確認すること

本書の記述をそのまま使えない7点（L4 §8）を、**確認事項に変換**したもの。

### 2-1. 「気軽に相談できる弁護士を確保する」[p.3] → 誰に相談できるのか

本書は法務部のないスタートアップに対して、**気軽に相談できる弁護士の確保**を勧める [p.3]。
VoC には**逆の問題**がある：**親会社に法務部がある。だがそれは Patchin の弁護士ではない。**

- 博報堂の法務部に相談したことは、**親会社に情報が渡ることを意味する**
- 「一回ドアノックしてNGが出たら覆らない」（STATE.md）という制約と正面からぶつかる
- 一方、VoC の予算で外部の弁護士を使えるのかは制度次第

**確認すること**：VoC の制度上、**外部専門家の費用を出せるか**。出せないなら、
親会社の法務部に何をどの順で相談するかを設計する必要がある（相談する前に相談先を決める）。

**これが決まらないと `patchin-decisions.md` §3 の8件が全部止まる。** 最優先の次に置く理由。

### 2-2. 「意思決定は取締役の決定」 → 何が正式な決定か

本書は取締役会非設置会社について、「取締役が集まっていつでも決定を行うことができ、
**電話で決定を行うこともできます**。また、会社法上は議事録を作成〔する必要もありません〕」と言う [p.58]。
**VoC では親会社の稟議規程が上位にある。**

本書の警告が別の形で効く：投資契約の**事前承諾事項を細かくしすぎると
「スタートアップ側の意思決定のスピードを奪ってしまい、その企業の発展にとって阻害要因になる」**[p.132]。
さらに**運用が形骸化すると「黙示に承認したと認定される可能性も高くなる」**[p.112]。

**VoC への読み替え**：稟議が何段階も挟まる構造は、**投資契約の事前承諾事項が過剰な状態と同型**。
そして**形骸化のリスクも同型**（「これは稟議を通さなくていいことになっている」の積み重ね）。

**確認すること**：どの決定に稟議が要り、どれが不要か、**書いてあるか**。
書いていないなら、それは後から「聞いていない」と言われうる状態。

### 2-3. 「役員の任期」 → VoC には役員がいない。だが法人化の瞬間に効く

本書：取締役の任期は原則2年、非公開会社なら定款で10年まで伸ばせる [p.63]。
**10年にしていると、辞めてほしいときに任期満了が使えず、解任すると残任期分の報酬が
損害賠償の基準になる** [p.65]。VC は2年以下を求めることが多い [p.64]。

**法人化時のチェック項目としてメモしておく。**（今は決められない）

### 2-4. 「自社が委託者・雇用主」 → 契約主体が誰か

`patchin-decisions.md` §1-2 と同じ論点だが、VoC 側の問いはこう：

- 外部エンジニアへの委託が**博報堂名義**なら、知財も**博報堂に帰属**しうる
- **下請法の資本金判定も親会社基準**になりうる [p.249–250]。該当すると
  **支払期日は受領日から起算して60日以内**に法的に縛られ、
  **レベニューシェア型の報酬は下請法違反リスク**がある [p.250]
- **フリーランス保護法には資本金要件がない** [p.374]。名義がどちらでも適用される。
  取引条件の明示義務（法3条）ほか

**確認すること**：委託契約の名義と、報酬の払い方。
レベニューシェアや成果連動で払う設計になっていたら、**下請法の適用有無を先に確定させる**。

### 2-5. 「就業規則・賃金制度は自社で整備」 → 親会社のものが適用される

- VoC の人員が博報堂の従業員（出向・兼務）なら、就業規則も賃金制度も親会社のもの
- **競業避止を VoC 独自に課せるか**は不明
- 労働時間の把握義務（労働安全衛生法66条の8の3）と厚労省ガイドライン [p.348] も親会社側の運用に乗る
- 未払い残業代の**消滅時効は5年（当分の間は経過措置で3年）**[p.343]

**確認すること**：PoC で打ち合わせを録音・分析する対象者が、**誰の従業員か**。
その人たちの労働時間・ハラスメント相談窓口が**どこにあるか**。
（`patchin-decisions.md` §3-4 の前提になる）

### 2-6. 「投資契約がある」 → 派遣役員の情報の持ち帰り

本書は投資家派遣の取締役について、**「何でも開示できるものではなく、開示する場合には、
発行会社の了解を得る必要があります」**とし、対処は「投資契約で定めておくことも1つの方法」[p.113]。

**VoC には投資契約がない。** 親会社から人が入っている場合、
その人が VoC の情報を親会社に持ち帰る根拠も制約も、**文書として存在しない可能性がある**。

**これは Patchin のデータ設計と直接ぶつかる。**
「評価に使わない一方向ファイアウォール」を技術で作っても、
**人が持ち帰る経路が空いていれば同じこと**。

**確認すること**：PoC で得たデータ・分析結果を、**誰がどこまで見られるか**を文書にする。
これは法律問題ではなく、思想3原則を運用に落とす作業（§4-1）。

### 2-7. 「出口（IPO/M&A）がある」 → VoC には出口がない。だが検査項目は残る

第IX章（M&A）・第X章（IPO）は出口の話。社内ベンチャーには IPO も M&A もない。

**だが L1 の横断で分かったこと**：DD のチェックリスト、IPO審査のチェックリスト、
L5 の【A】（仕組みを作る前にしか作れないもの）は**同じ項目に収束する**。
理由は単純で、**買い手も証券会社も「後から直せないもの」しか見られないから**。

つまり **DD・IPO審査の項目は、出口がなくても「普段やっておくべきこと」のリストとして読める。**

特に効くもの：
- **知的財産権が役職員・取引先との契約で確保できているか** [p.412] → §1
- **親会社との取引条件**：M&A では「存続させるか解消するか」が論点になり [p.397, p.399]、
  IPO では「事業に必要性のない関連当事者取引はIPO前に解消」[p.411] される
  → **VoC が親会社に依存した条件で回っていること自体が、将来の選択肢を狭める**

## 4. 決めるのは自分

### 4-1. 一方向ファイアウォールを「人」にも適用するか

技術的なファイアウォールは STATE.md で「機能要件（破るとデータ資産が死ぬ）」と位置づけられている。
**だが §2-6 のとおり、人が持ち帰る経路は塞がれていない。**

決めるべきこと：
- PoC の分析結果を、**親会社の誰が見られるか**
- 「見られる」と「使える」を分けるか（見せるが人事評価には使わせない、を運用でどう担保するか）
- **見せないと決めた場合、8月末の報告会で何を見せるのか**

これは思想の問題であり、**先に決めておかないと報告会の場で流される**。
本書の言葉で言えば、事前承諾事項の**形骸化**が起きるのと同じ経路 [p.112]。

### 4-2. 親会社との取引条件を、いま有利にしておくか

§2-7 のとおり、親会社に依存した条件は将来の選択肢を狭める。
**だが今は親会社の支援があるから成立している。**

- 「今の有利な条件で回す」＝立ち上がりが速い。将来 DD で論点になる
- 「最初から独立採算に近い条件にする」＝立ち上がりは遅い。将来の選択肢は広い

**出口がない前提なら前者でよい。** ただし**「後で選択肢を狭める」と分かったうえで選ぶ**のと、
気づかずに選ぶのは違う。稟議資料に書いておく価値がある。

### 4-3. 内部通報窓口を独自に持つか

本書：常時使用する労働者**300名以下は体制整備が努力義務** [p.420 注3]。
VoC 単体なら該当する。

- 親会社の窓口を使う → 作らなくてよい。**ただし通報者の秘密保持と親会社への情報流通が緊張する**
- 独自に置く → 少人数で誰が担当するのか（本書はここに踏み込んでいない：L4 §7）

**今は決めなくてよい。人が増えた時点の宿題としてメモ。**

## 5. 今は決めない（保留と、再検討のトリガー）

| 保留するもの | 再検討するトリガー |
|---|---|
| 種類株式・投資契約の条項（第IV章のほぼ全部） | **外部資本が入ると決まった瞬間**。そこから一気に効く |
| 創業株主間契約 | 同上。ただし**「メンバーが抜けたとき何が残るか」**（プロダクトの権利・ノウハウ・顧客との関係）は今から考えておける |
| 役員の任期（§2-3）、定款の総数引受規定 | **法人化・定款作成の瞬間**。定款は設立時に入れるのが最も安い [p.71] |

| 外為法の届出（§3-6） | 資本構成が決まる直前。**待期期間があるので、決まってから調べるのでは遅い** |

## 6. この文書の限界

- **VoC の制度そのものを読んでいない。** 博報堂の社内ベンチャープログラムの規程、
  投資委員会の条件、法人化のスキームを見ずに書いている。
  §1・§2-1 の答えは**そこに書いてある可能性がある**
- **特許の出願人・発明者が実際にどうなっているかを確認していない。**
  §1 は「確認せよ」であって「こうなっている」ではない
- **本書は独立資本のスタートアップの本である**（L4 §8）。
  親子会社間の論点（親会社の規程が子会社にどう及ぶか、グループ内の情報流通）は
  **本書の射程外**であり、この文書の読み替えは**本書の裏付けを持たない**
- STATE.md が 2026-07-22 時点。8月中旬の稟議、8月末の報告会が予定どおりだったかを確認していない
