# 読む目的と事業文脈

L1〜L4（要点抽出・章統合・構造化・批判的検討）は本の中身だけで書ける。
この文書が効くのは **L5（事業への適用）以降**。
本の解釈と、こちらの事情は混ぜないため、文脈はここに隔離しておく。

## 目的

**創業者としての法務リテラシーを持つこと。** 法務の実務そのものを解くことではない。

利用者の立場: Patchin の実法務には専門家を入れる前提。したがってこの本に求めるのは
「正しい答え」ではなく、**専門家に渡す前に自分で気づける状態**。

具体的な用途は2つ:

1. **VoC の起業トラックの実務** — 社内ベンチャーの立ち上げで実際に判断が要る場面
2. **知識として持っておく** — 適用先は未定。将来の判断のための素地

## この目的から導かれる、L5で出すべきもの

| 出すもの | なぜ |
|---|---|
| **取り返しがつかない論点の一覧** | 後から直すのに相手の同意が要る論点は、気づくのが遅れた時点で打ち手が消える。創業者リテラシーの核 |
| **専門家に相談すべきタイミング** | 「何を知っているか」より「いつ人を呼ぶか」が実務では効く |
| **相談時に聞くべきこと・渡すべき材料** | 論点を持たずに相談すると、専門家の時間が状況把握で消える |
| **自分で判断してよい範囲 / 絶対に判断してはいけない範囲** | 線引きが無いと、過剰に止まるか、踏んではいけない所を踏む |

出さないもの: 条項の書き方の指南、Patchin固有の法的結論。
どちらも専門家の領分で、この本とこの読み方では担保できない。

## 適用上の前提差 — VoC（社内ベンチャー）

本書は**通常のスタートアップ**（独立資本・自社株・創業者が株主）を前提にしている。
社内ベンチャーは前提が違うため、そのまま当てはまらない主張がある。

| 本書の前提 | VoCでの実際 | 扱い |
|---|---|---|
| 創業者が自社株を持つ | 親会社の一部門/子会社。持分設計の余地が限定的 | 第II章・第IV章・第V章の多くは射程外の可能性。`open_questions` に立てる |
| 資本政策は創業者が決める | 親会社の規程・稟議が上位にある | 意思決定の主体が違う点を明記する |
| 資金調達は外部投資家から | 社内予算/親会社出資 | 投資契約の条項論は「知識として」の側に寄せる |
| 職務発明は自社の規程 | 親会社の職務発明規程が適用されうる | 第VII章 QVII-3 は要確認事項として残す |

**射程外だから読み飛ばす、はしない。** 全ページを一度は通す方式なので L1 カードは全バッチ作り、
「なぜこの章はVoCに当てはまらないか」を L4 で記録する。
当てはまらない理由を書き残すこと自体が、2つ目の目的（知識として持つ）に対する成果になる。

## 出典の書き方（この本の固有事情）

- **印刷ページ = スクリプトのページ番号 − 16**（scan 0020 → 印刷 p.5、scan 0250 → 印刷 p.235 で検証済み）
- 引用は `[p.235 (scan p.0251)]` の形式
- **枠囲みの契約条項はOCRが弱い**。「乙」の認識率が約75%（8箇所中6箇所）。
  条項を引くときは必ずページ画像で確認してから書く

## OCRの弱点（第1本文ページで実測・2026-08-02）

地の文は約98%正確。argumentを追うには十分。ただし次は**必ずページ画像で確認**してから書く。

| 弱点 | 実例 | なぜ危険か |
|---|---|---|
| **番号付き列挙** | `(4)` → `(3④)` | 法務書は「①要件②例外③手続」の列挙で意味が決まる。条項番号のズレと同じ |
| 枠囲みの契約条項 | 「乙」の認識率 約75% | 甲乙が入れ替わると当事者が逆になる |
| 濁点・半濁点 | レピュテーション → レビュテーション | 用語の同定を誤る |
| 字形の近い漢字 | 滅多 → 減多 | 文意は通るので気づきにくい |
| 図版・装飾由来 | 章バッジ→`= 。` / Aマーカー→`Leo` `ZF` / しかし→`LOL` | 存在しない語が生成される |

**運用**: L1カードで「著者の主張」として列挙・条項・数字を書くときは、
その都度スキャン画像に戻る。地の文の要約はOCRのままでよい。
