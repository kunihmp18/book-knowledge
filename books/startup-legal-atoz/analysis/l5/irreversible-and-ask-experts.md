## 0. 本書自身が最初に置いた「失敗例15項目」

【著者】第I章 QI-3 に、著者が挙げる失敗例が15項目ある [p.9–18]。
**この文書の【A】と大半が重なる。** 著者は最初に「後から効いてくるもの」を並べ、
各章で詳述する構成をとっている。

⑴設立時の発行株式数が少なすぎる ⑵創業者間の持株比率の設定で失敗 ⑶初期の段階で第三者に
株式を割り当てすぎる ⑷最初の資金調達の際に条件交渉をしっかりしない ⑸ストックオプションの
発行で失敗 ⑹議事録類を紛失する ⑺定款の更新をしていない ⑻商標を取得していない
⑼電気通信事業法の届出をしていない ⑽業務委託をする際に知的財産権が確保できていない
⑾従業員の雇用に関する必要な手続を履行していない ⑿従業員を解雇してしまう
⒀種類株主総会決議を忘れる ⒁取締役会の決議要件を満たしていない
⒂他の案件の契約書を不適切に流用してしまう

【評】**この15項目を年1回読み返すだけでも、かなりの事故を防げる。**

## 1. 取り返しがつかない論点 — いつ効くかで並べる

### 【A】仕組みを作る前にしか作れないもの

後から作っても遡らない。**気づいた時にはもう手遅れ**という類。

| 論点 | 手遅れになる理由 | 出典 |
|---|---|---|
| **創業者株主間契約** | 仲が良いうちにしか結べない。結ばずに揉めると**「最悪の場合には会社を一から作り直す」** | p.30 |
| **会社化前のプロダクトの権利移転** | 著作権は創作した**個人に帰属**（発生主義）。時間が経つと**気まずくて頼めなくなり、対価も上がる** | p.35, p.38 |
| **設立時の発行株式数を多めにする** | 100株だと1株が1%。後から株式分割するには株主総会と登記が要る | p.9–10, p.44 |
| **定款に総数引受・譲渡承認の別段の定めを置く** | 設立時なら無料。後から入れるには定款変更（特別決議） | p.71, p.79 |
| **役員の任期を1〜2年にしておく** | 10年だと辞めてほしいとき任期満了が使えず、解任すると**残り任期分の賠償** | p.64, p.65–66 |
| **職務発明の規程** | 発明の後に制定した規程は拘束力が争われる。制定前の発明は個別に譲渡を受けるしかない | p.318, p.412 |
| **賃金制度・評価制度** | 制度がないと「評価が悪いので減給」が適法にできない。**制度は遡って作れない** | p.355 |
| **SOの「退職したら権利を消滅させる」規定** | 付与時の設計にしか入れられない。発行後の変更は株主総会＋**全権利者の同意** | p.183, p.191 |
| **SOの枠を残しておく** | 上場時**10〜15%以内**が目安。幹部採用前に使い切ると採用力を失う | p.12–13 |
| **優先株式の希薄化防止の方式** | フルラチェットか加重平均か、ナローかブロードかは発行時に決まる | p.158 |
| **取得条項（IPO前の強制転換）** | 入れていないと優先株主が転換を拒否したとき上場が進まない | p.160–161 |
| **秘密情報のアクセス制限** | 持ち出された後に「実は秘密管理していた」とは主張できない | p.321, p.365 |
| **同意取得のログとバージョン管理** | 取っていなかったログは遡って作れない | p.219 |
| **広告の裏付け資料** | 表示を出す前に取得・保存していなければ、優良誤認とみなされる（不実証広告規制） | p.278 |
| **漏洩時の初動手順** | 報告期限は**発覚日から3〜5日**。発覚してから調べ始めると溶ける | p.288 |
| **無償ポイントの区分管理** | 発行時点で区分していなければ、後から「これは無償分」と主張できない | p.269 |
| **懲戒の段階を踏む運用** | 一度不問に付した事案に後から処分は課せない | p.360 |
| **議事録の原本還付** | 登記に原本を出したまま還付手続をしないと**法務局に保管され手元に残らない** | p.13 |
| **違法利用を排除する仕組み・体制・運用実績** | IPO審査で**「①仕組み、②体制、③運用実績」**が問われる。実績は遡って作れない | p.8 |

### 【B】契約に書いていなければ、後は相手の同意次第

相手が「はい」と言わなければ直せない。**交渉力が落ちてからでは動かない**。

| 論点 | 何が起きるか | 出典 |
|---|---|---|
| **最初の資金調達で重い義務を飲む** | **前のラウンドの義務は次のラウンドでも負わされる**。一度優先株式で調達すると以後も優先株式が通常 | p.12 |
| **株式買取条項の対象に経営者個人が入る** | 発動されると**「投資家の取得価額」**（＝払い込まれた金額）が請求されうる | p.140–143 |
| **株式買取条項の発動事由** | 「一定期間内に是正しない場合」「重要な点についての違反のみ」「合理的な理由なく上場しない場合」への限定は締結時にしか入れられない | p.141–142 |
| **キーマンクローズの期間・報酬・地位保証** | **拘束だけされて地位が保証されない**設計になりうる。解任権の行使で地位を失う | p.404–405 |
| **競業禁止の禁止対象と起点** | 「M&Aより〇年間」にする、退職後にやりたい事業を除外する — 締結時にしか動かせない | p.406 |
| **ドラッグ・アロング・ライトの発動要件** | 「時期」と「金額」を織り込み損ねると、**投資家の意向だけで会社の売却を強制されうる** | p.119 |
| **みなし清算に全株主を拘束する** | 一部だけだと同じ普通株式に**1物2価**が生じ、**M&A自体の支障**になる | p.127 |
| **表明保証のただし書（例外事項の明記）** | **条項全体の削除を求めてはいけない**（他の保証まで消える） | p.105–106 |
| **「知る限り」の挿入** | 入れないと、知りようのない事実まで保証したことになる | p.107 |
| **新株等の優先引受権からSO発行を除外** | 除外しないと将来のSO発行にも投資家の優先引受権が及ぶ | p.135 |
| **Change of Control条項の入った契約を結ぶ** | **M&Aのときに相手の同意が要る**。契約時には気づきにくい | p.397 |
| **業務委託の知財帰属** | 契約に書かなければ**受託者に残る**。報酬を払っても移らない | p.247, p.14 |
| **著作権法27条・28条の明記** | 「著作権を譲渡」だけでは翻案権等が**留保されたと推定**される（61条2項） | p.36, p.247, p.413 |
| **著作者人格権の不行使特約** | 人格権は契約でも移転しない（59条）。特約がなければ相手は行使できる | p.37, p.247 |
| **第三者との契約が個人名義** | Apple・ドメイン・サーバー等。会社への名義変更に**相手方の同意**が要る | p.39 |
| **退職後の競業避止・秘密保持** | 入社時に定めていないと、**揉めた退職者からは誓約書を取れない** | p.363–364 |
| **サイニングボーナスの支払い方** | 一括で払うと返還を求められない可能性が高い | p.382–383 |
| **ライセンスの競業禁止条項** | IPO時の解消には**相手方の確認書**が要る | p.256 |
| **契約時の損害賠償の上限設定** | **本文の最後の文**。紛争のリスク範囲を客観的に説明できるようにする | p.425 |

### 【C】一度やってしまうと戻せない

| 論点 | 戻らないもの | 出典 |
|---|---|---|
| **株式を出す** | 出すのは総数引受で**最短1日**。戻すのは財源規制＋減資2カ月＋売主追加請求権＋みなし配当課税の**4重の壁** | p.71, p.81–83 |
| **初期に第三者へ株式を割り当てすぎる** | 著者いわく**「致命傷」「基本的には不可逆」** | p.10–11 |
| **従業員に株式を渡す** | 退職しても消滅させられない。会社が買うと財源規制、**違反は刑事罰**（会社法963条5項1号） | p.182 |
| **取締役会の過半数を失う** | 株主総会の招集に取締役会決議が要るため**すぐには戻せない** | p.109–110 |
| **解任してしまう** | 登記簿に「解任」と残り、**IPO・M&Aで詳しく調査される**。本人の次の就職の障害にも | p.66 |
| **累積型の優先配当を受け入れる** | 未払額が累積し、**IPOの支障になりうる** | p.153 |
| **事前承諾手続を形骸化させる** | 黙認状態が続くと**黙示の承諾・権利濫用**を認定されやすくなる | p.132 |
| **投資契約に内容を確認せずサインする** | 回収フェーズの投資家は表明保証違反を探す。**厳しい回収攻撃** | p.104–105 |
| **NDAへのサイン** | 独占交渉権や競業禁止が紛れていても「聞いていない」は通らない | p.244 |
| **NDAなしでの情報開示** | **1人にでも秘密保持契約なしで開示すると非公知性を失う**可能性 | p.244–245, p.322 |
| **投稿物の権利帰属条項** | 「無償で全て譲渡」と書いて炎上すると、条項を直しても評判は戻らない | p.214 |
| **商標を取られる** | 名称を変えても**それまでの侵害の賠償義務は残る** | p.312 |
| **漏洩の最初の公表内容** | 過小に発表して後から拡大すると隠蔽体質を疑われる | p.289 |
| **公表しない判断** | ダスキン事件（大阪高判平18.6.9）で**取締役の善管注意義務違反**と認定 | p.289 注3 |
| **AI学習時の目的設定** | 学習後に「享受目的ではなかった」と作り直せない。**設計時点で決まる** | p.334 |
| **違法状態のまま許認可なしで始める** | 後から取得しようとすると**過去の違法状態について刑事罰**が科されないかの問題が生じる | p.414 |

### 【D】時間が経つと消える／間に合わない

| 論点 | 期限 | 出典 |
|---|---|---|
| **登記** | 変更から**2週間以内**。過ぎると**100万円以下の過料**。登記申請日は謄本に残り言い訳できない | p.49–50 |
| **譲渡承認請求への回答** | **2週間**放置すると承認したものとみなされる | p.79 |
| **「総会で枠をとる」** | 委任の効力は**1年間**。1年以上前の枠は使えない | p.69 |
| **減資** | 官報公告1カ月＋申込に中5営業日。**決算公告を怠っていると中11営業日**に伸びる | p.76–77 |
| **債権者保護手続（合併等）** | 催告1カ月＋官報公告1〜3週間で**おおむね2カ月** | p.393 |
| **取得条項の発動と上場申請** | 株主への2週間前通知。株券発行会社は**1カ月前までの株券提供公告**も要る | p.161 注1 |
| **外為法の事前届出の待期期間** | 届出後、法令上30日（**実務上2週間程度**）満了まで株式を取得できない | p.176 |
| **グレーゾーン解消制度** | 回答は1カ月以内が原則だが、**事前相談開始から3カ月を目途**。サンドボックスは数カ月 | p.20–21 |
| **誹謗中傷の発信者情報** | プロバイダのログ保存は**一般的に3カ月程度** | p.297 |
| **未払い残業代** | 消滅時効5年（当分は経過措置で3年）。**過去分がIPO・M&Aで必ず出てくる** | p.348 |
| **売掛金の消滅時効** | 内容証明の催告で6カ月延ばせるが、完成すれば請求権自体が消える | p.299 |
| **個人データの利用目的** | 変更は**「相当の関連性」**の範囲内。取得時の公表内容が後の利活用範囲を決める | p.222–223 |

## 2. 専門家に相談すべきタイミング

**「何を知っているか」より「いつ人を呼ぶか」**。以下は本書が明示的に専門家を勧めている箇所。

| タイミング | 誰に | 本書の記述 |
|---|---|---|
| **サービスの適法性が不明なとき** | 弁護士 | 「各法律の広範な知識が必要なため、このような業務に慣れた弁護士に依頼するのが望ましい」[p.6]。財務的に難しくても**「明らかに規制に抵触するものではないことを最低限確認」**[p.7] |
| **最初の資金調達の投資契約** | 弁護士 | **「調達額やその他の状況にかかわらず、一度は投資契約等のリーガルチェックを受けるべき」**[p.12] |
| **資本政策を決めるとき** | 専門家一般 | **「基本的には不可逆なものですので、起業の前後でいろいろな人の意見を聞いたうえで決定する」**[p.11] |
| **J-KISS等で投資家と契約交渉する段階** | 弁護士 | 「必要に応じて専門家に相談することも検討しましょう」[p.89] |
| **新株予約権付社債（CB）を発行するとき** | 弁護士 | 「上記の2つに比較すると**難易度が高く、専門家に相談したほうが安全**」[p.96] |
| **CBの転換条件の調整条項を読むとき** | 弁護士 | 「**投資家側に有利な内容になっている場合もある**」[p.170] |
| **ベンチャーデットでの調達** | 税理士・会計士 | 「税務・会計の専門家への相談も適時に行う必要がある」[p.175] |
| **税制適格SOを設計するとき** | 弁護士・税理士 | 「きちんと税制上の優遇措置も満たす形で設計する場合は専門家への相談をしたほうがよい」[p.181] |
| **自己株式の取得（分配可能額の判定）** | 税務会計の専門家 | 「分配可能額は…会社にあるキャッシュの金額とイコールではない」[p.182 注2] |
| **自己株式取得のみなし配当課税** | 税理士 | 「譲渡人が認識していないと後からトラブルにもなりかねません」[p.83] |
| **チームのプロダクトを会社に譲渡する価格** | 税理士 | 「客観的にみて価値のあるものをその価値より安く譲渡してもらう場合は税務上の問題」[p.37] |
| **減資の税務メリットの判定** | 税理士 | 「税制改正の対象になることも多いですので、税理士等の専門家へ相談したほうが安全」[p.75] |
| **登記手続** | 弁護士・司法書士 | 内部に登記実務の経験者がいなければ「専門家に頼んだほうがよい」[p.13] |
| **サービス・商品名を決める段階** | 弁理士 | **「サービス・商品名決定の段階から、商標戦略を弁理士に積極的に相談したほうがよい」**[p.314] |
| **みなし残業代・裁量労働制・管理監督者の設計** | 社労士/弁護士 | 「社会保険労務士や弁護士等にも相談するなどして慎重に検討をしたほうが安全」[p.350] |
| **職務発明規程の制定と金額査定のプロセス設計** | 弁理士/弁護士 | 協議・開示・意見聴取の**プロセスが有効性を左右する**[p.318] |
| **個人データを外部から受け取る/外部に預けるスキーム** | 弁護士 | 提供元基準・匿名加工・仮名加工＋共同利用のどれを採るか [p.326–331] |
| **消費者向けサービスの免責条項** | 弁護士 | **他社の規約を写すと古い法令のまま**（サルベージ条項が2023年施行で無効に）[p.216] |
| **下請法の適用判断** | 弁護士 | 「資金調達により資本金が高くなっているケースが多く、**親事業者に該当しやすい**」[p.250] |
| **漏洩が発覚した直後** | 顧問弁護士 | 「顧問弁護士等とも相談のうえ」[p.287] |
| **解雇・退職勧奨を行う前** | 弁護士 | 無効なら給与と遅延損害金を遡って払う [p.361]。「ただちに解雇に踏み切るのは避けるべき」[p.15] |
| **事業の根幹に関わるライセンス契約** | 弁護士 | 解除条項・期間・競業禁止 [p.256–258] |
| **AI学習の目的が享受目的と併存しないかの評価** | 弁護士 | 「作風」の議論は判断が微妙 [p.334] |
| **新規ビジネスで許認可が要るか微妙なとき** | 弁護士＋官公庁 | IPO審査で**①弁護士の意見書②関連官公庁の見解の確認**を要請される [p.411] |
| **IPO審査で問題が見つかったとき** | IPO実務の専門家 | 「多くのIPOの現場に携わっている専門家でないと判断が難しい」[p.410] |
| **M&Aのキーマンクローズ交渉** | 弁護士 | 「**信頼ベースで行きましょう**と言われても…弁護士等のアドバイザーに入ってもらう」[p.406] |

### 相談前に自分で用意しておくもの

- **自分がどちら側か**（開示者/受領者、委託者/受託者、ライセンサー/ライセンシー、供給者/代理店）

## 3. 交渉の型 —「ゼロか100か」にしない

【評】本書を通じて繰り返し現れる型。**まったく違う条項に同じ解が出ている。**

| 場面 | ゼロ100の罠 | 著者の解 |
|---|---|---|
| **ドラッグ・アロング・ライト** [p.119] | 「入れるか否か」で争うと**「投資を受け入れるか否かという究極的な交渉」**になる | 困っているのは**「時期」と「金額」**。発動要件に織り込む |
| **取得条項（IPO前の強制転換）** [p.161–162] | 入れないとIPO前に転換できない／入れると投資家が優先権喪失リスク | **入れたうえで戻せるようにする**（一定期間内にIPOできなければ元の優先株に戻す） |
| **表明保証で事実と違う点があった** [p.106] | 条項全体の削除を求める → **他の保証まで消えるので応じてもらえない** | **ただし書で例外事項だけを明記** |
| **株式買取条項** [p.141–142] | 条項自体を外せないことが多い | **発動事由を自分でコントロール可能な範囲に限定** |
| **規制に抵触しそうなビジネス** [p.6] | 「諦める」か「強行する」か | ⒤規制に則った運用 ⒤⒤**規制の適用対象外となるスキームを構築**。「ただちに諦める必要はありません」 |
| **キーマンクローズ** [p.405–406] | 全面拒否は難しい（M&Aの前提条件にされる） | **期間の起点をM&A時点にする／禁止対象から特定事業を除く／賠償額に上限** |

**使い方**: 受け入れがたい条項が来たら、「拒否する／呑む」の前に
**「相手が本当に確保したいものは何か」→「それを満たしつつ自分のリスクを削る条件は何か」**
を1回挟む。

## 4. 自分で判断してよい範囲

【評】本書の記述から導いた線引き。**これらは専門家を呼ぶ前に自分で確認できる。**

### 契約書を受け取ったとき（一般）

**まず「自分はどちら側か」を確認する。** 同じ条項でも立場が逆なら有利不利が反転する。

著者が示す修正テクニックのうち**②③④は機械的に適用できる** [p.236–237]:

| # | 直し方 |
|---|---|
| ② | 「防止**しなければならない**」→「防止**するよう努め**なければならない」 |
| ③ | 「甲の指示に従う」→「甲の**合理的な**指示に従う」 |
| ④ | 「**乙**は」→「**甲および乙**は」、「**甲**の秘密情報」→「**相手方**の秘密情報」 |

著者は④について「**汎用性がありますので、是非使ってみてください**」[p.237]。

- NDA: **目的外使用の禁止**があるか [p.242]
- NDA: 独占交渉権・競業禁止が紛れていないか（**条項の表題ではなく本文を読む** [p.244]）
- 業務委託: **著作権法27条・28条**と**著作者人格権の不行使**が書かれているか [p.247]
- 全般: **競業禁止規定**と**任意解除規定**（著者が「特にリスクが大きい」とする2つ [p.233–234]）
- **他の案件の契約書を流用していないか** — ①前の相手の情報が残る ②大企業向けの不利な条件を
  そのまま使う ③実態と合わない（売買型の契約を仲介型に流用）[p.16–18]

### 投資契約を受け取ったとき

**表明保証条項は3つに分類するところまで自分でできる** [p.105]:

| 分類 | 手当て |
|---|---|
| ①正しい | そのまま |
| ②異なる事実がある | **ただし書で例外を明記**（条項全体の削除を求めない） |
| ③自分ではわからない | **「発行会社の知る限り」**を挿入 |

投資家から**「知り得る限り」への修正を求められたら、それは別物**。
「合理的に調査すれば分かった」事項まで保証させる意味で、調査不足の落ち度があれば免責されない [p.107]。

- **株式買取条項の請求対象に経営者個人が入っているか**（2022年3月の公取委・経産省の指針が
  「個人を除いていくことが競争政策上望ましい」としている [p.140]）
- **ドラッグ・アロング・ライトの目的はどちらか** [p.115, p.119]
- **取締役の派遣を受け入れた場合、取締役会の過半数をキープできるか** [p.109]。
  **オブザーバー＋情報請求権**という中間解がある [p.108–109]
- **新株等の優先引受権からSO発行が除外されているか** [p.135]
- **拒否権が「自分だけのもの」か「種類株主総会の決議事項」か** [p.150]

### 自社の状態（今すぐ確認できる）

- **定款は最新か**（wordファイルを持っているか）[p.13–14]
- **役員の任期は1〜2年か**（10年になっていないか）[p.64]
- **定款に総数引受契約の承認・譲渡承認の別段の定めがあるか** [p.71, p.79]
- **登記漏れがないか** — ①目的追加 ②本店移転 ③**代表者の引っ越し** ④**重任** ⑤SOの放棄 [p.49]
- **決算公告をしているか**（全株式会社の義務。過料あり）[p.57]
- **議事録が揃っているか**（原本還付をしているか）[p.13]
- **商標を取得しているか**（特許庁の検索サイトで自分で見られる [p.312]）

### 自社のサービスについて

- **法律構成が売買型か仲介型か明確か**。売上の計上が構成と合っているか [p.5–6]
- 同意画面が[p.218]の「適切な事例」の形か（**掲載しているだけでは効かない** [p.217]）
- 規約ページへのリンクが**直接飛ぶ**か、リンク切れがないか [p.219]
- **同意ログとバージョン管理**を取っているか [p.219]
- プライバシーポリシーの利用目的が抽象語で終わっていないか [p.223]
- 禁止事項に**ペナルティが対で**書かれているか [p.210]
- **違法利用を検出・排除する仕組みと運用実績があるか** [p.8]

### 社内について

- 入社時の**誓約書**に⒤知財帰属 ⒤⒤秘密保持 ⒤⒤⒤反社不該当 ⒤ⓥ競業避止 ⓥ勧誘禁止 [p.345]
- **株式を渡す相手を絞れているか**（原則SO、例外的に幹部候補のみ株式 [p.180]）
- SOの発行要項に**「退職したら権利を無償で会社が取得できる」**が入っているか [p.183]
- **SOの発行済比率**（上場時10〜15%以内が目安。幹部枠を残しているか）[p.12–13]
- 労働時間を**客観的な記録**（PCログ等）で把握しているか [p.348–349]
- 社内の情報に**アクセス制限と「秘密」表示**があるか [p.321]
- ハラスメントの**相談窓口を定めて周知**しているか [p.371]
- **漏洩時の初動手順を紙に書いてあるか**
- 投資契約の**事前承諾手続を実際に回しているか** [p.132]

### フリーランスに委託するとき

- 契約書・発注書のひな型に**8項目**が網羅されているか [p.374]
- 支払期日が**受領日から60日以内**か（検査完了時点ではない [p.375]）
- 6カ月以上の契約なら**30日前予告**の条項があるか [p.378]
- 契約不適合責任の期間が**1年を超えていない**か [p.376]

## 7. Patchin／VoC で未解決の論点

本書からは答えが出ない。**専門家に聞くべき筆頭**。

### データ・プライバシー（Patchin本体）

1. **アセスメントスコアは「要配慮個人情報」に当たるか。**
   本書の定義（人種・信条・社会的身分・病歴・犯罪の経歴等 [p.287 注1]）には直接該当しない
   ように見えるが、**心理的特性が「信条」に接近しうるか**は判断できない。
   当たるなら**1件の漏洩でも報告義務** [p.288]。
2. **提供元基準が Patchin のデータフローにどう当たるか。**
   顧客企業が誰のスコアか分かっている以上、提供先で氏名を持たなくても第三者提供に
   当たりうる [p.326]。本書の設問は医療データで、要配慮個人情報という別の重さがある。
3. **「適法利用性」の観点から、顧客企業による目的外利用をどう防ぐか。**
   本書は「サービス自体が適法でも違法行為に利用される可能性」を論じ、
   **知りながら放置すると加担と判断されうる**とする [p.7]。
   `docs/strategy_for_business.md` の**「監視しない・評価に使わない」は、
   思想であると同時に適法利用性の設計**として読み直せる。
4. **利用目的をどこまで狭く書くか。**
   狭く書けば思想が守られるが、本書は「将来の変更可能性も考慮」と言う [p.223]。
   **法律問題ではなく経営判断。**
5. **PoCの記録と労務管理の交差。**
   パワハラ指針の「個の侵害」に**「労働者を職場外でも継続的に監視すること」**が挙がっている
   [p.367]。`docs/poc_plan_voc.md` の対象は業務中の打ち合わせだが、**論点として接続する**。
6. **Patchinの法律構成は売買型か仲介型か、どちらでもないか。** [p.5–6]
   売上計上と適用法令が変わる。**明示的に決めているか**という問い。

### VoC（社内ベンチャー）— ガバナンスと人

7. **親会社から VoC に役員が入る場合、その人が VoC の情報を親会社に持ち帰る根拠は何か。**
   本書は投資家派遣の取締役について「**何でも開示できるものではなく**、開示する場合には、

9. **VoC の職務発明は誰のものか。** 親会社の職務発明規程が適用される可能性。
   本書は自社で規程を作る前提 [p.315–318]。
10. **下請法の資本金判定は親会社基準か。** 該当すると支払条件が法的に縛られる [p.250]。
11. **VoC の人員に SO を出せるか。** 出向者や親会社従業員の場合、税制適格の
    「取締役または従業員」要件をどう満たすか。
12. **親会社が「外国投資家」に該当する可能性はないか。** 日本法人でも外国の非居住者・

13. **VoC が親会社に依存した取引条件で回っている場合、それ自体が将来の選択肢を狭めないか。**

14. **VoC の「Exit」に相当するものは何か。** 第IV章の全条項は Exit の確保を前提に組まれている。
    社内ベンチャーには IPO も M&A もない。
    ただし**DDとIPO審査のチェック項目は、出口がなくても「普段やっておくべきこと」として
    意味を持つ**（本文書の【A】と一致）。
15. **VoC の内部通報窓口は誰が持つのか。** 300名以下は努力義務 [p.420 注3]。
    親会社の窓口を使うのか独自に置くのか。**通報者の秘密保持と親会社への情報流通が緊張しうる。**
16. **Patchinの特許（`docs/patent_alignment.md`）は、DDの「資産」で見られる。**
    「③会社の役職員との契約および取引先との契約で知的財産権が確保できているか」[p.412]。
    **③が外部エンジニア委託（`docs/engineer_brief.md`）と直結する。**
    この論点は**第I章 [p.14]・第II章 [p.38]・第VI章 QVI-6・第IX章 [p.398]・第X章 [p.412] の
    5箇所から同じ指摘**が来ている。本書で最も繰り返された警告。
