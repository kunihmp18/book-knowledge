## 1. 取り返しがつかない論点 — いつ効くかで並べる

### 【A】仕組みを作る前にしか作れないもの

後から作っても遡らない。**気づいた時にはもう手遅れ**という類。

| 論点 | 手遅れになる理由 | 出典 |
|---|---|---|
| **職務発明の規程** | 発明の後に制定した規程は拘束力が争われる。制定前の発明は個別に譲渡を受けるしかない（＝発明者の同意が要る） | p.318 |
| **賃金制度・評価制度** | 制度がないと「評価が悪いので減給」が適法にできない。**制度は遡って作れない**。著者も「適法にこれを行うことが難しいのが実情」と | p.355 |
| **SOの「退職したら権利を消滅させる」規定** | 付与時の設計にしか入れられない。発行後の内容変更は株主総会の承認＋**全権利者の同意** | p.183, p.191 |
| **創業株主間契約（株式を渡す前に）** | 株式を持ってもらう際に退職時の買取りを合意しておく。**渡した後では相手の同意が要る** | p.182 |
| **優先株式の希薄化防止の方式** | フルラチェットか加重平均か、ナローかブロードかは発行時に決まる。ダウンラウンドが来てからでは動かせない | p.158 |
| **取得条項（IPO前の強制転換）** | 入れていないと優先株主が転換を拒否したとき上場が進まない。後から入れるには**定款変更＋種類株主総会** | p.160–161 |
| **秘密情報のアクセス制限** | 持ち出された後に「実は秘密管理していた」とは主張できない。営業秘密の「秘密管理性」は事前の実態がすべて | p.321, p.365 |
| **同意取得のログとバージョン管理** | 取っていなかったログは遡って作れない。紛争時に「どの版に同意したか」を示せない | p.219 |
| **広告の裏付け資料** | 表示を出す前に取得・保存していなければ、提出を求められた時点で優良誤認とみなされる（不実証広告規制） | p.278 |
| **漏洩時の初動手順** | 報告期限は**発覚日から3〜5日**。発覚してから手順を調べ始めると溶ける | p.288 |
| **無償ポイントの区分管理** | 発行時点で区分していなければ、後から「これは無償分」と主張できない | p.269 |
| **懲戒の段階を踏む運用** | 一度不問に付した事案に後から処分は課せない。解雇の相当性も積み上がらない | p.360 |

### 【B】契約に書いていなければ、後は相手の同意次第

相手が「はい」と言わなければ直せない。**交渉力が落ちてからでは動かない**。

| 論点 | 何が起きるか | 出典 |
|---|---|---|
| **株式買取条項の対象に経営者個人が入る** | 契約締結時にしか交渉できない。発動されると**「投資家の取得価額」**（＝払い込まれた金額そのもの）が請求されうる | p.140–143 |
| **株式買取条項の発動事由** | 「一定期間内に是正しない場合」「重要な点についての違反のみ」「合理的な理由なく上場しない場合」への限定は、締結時に入れるしかない | p.141–142 |
| **ドラッグ・アロング・ライトの発動要件** | 「時期」と「金額」を織り込み損ねると、**投資家の意向だけで会社の売却を強制されうる** | p.119 |
| **みなし清算に全株主を拘束する** | 一部株主だけの合意だと、同じ普通株式に**1物2価**が生じ、税務リスクに加え**M&A自体の支障**になる | p.127 |
| **表明保証のただし書（例外事項の明記）** | 事実と違う保証をしたまま契約が成立する。**条項全体の削除を求めてはいけない**（他の保証まで消える） | p.105–106 |
| **「知る限り」の挿入** | 入れないと、自分が知りようのない事実まで保証したことになる。投資家からは「知り得る限り」を求められる | p.107 |
| **新株等の優先引受権からSO発行を除外する** | 除外しないと、将来のストックオプション発行にも投資家の優先引受権が及ぶ | p.135 |
| **業務委託の知財帰属** | 契約に書かなければ**受託者に残る**。報酬を払っても移らない | p.247 |
| **著作権法27条・28条の明記** | 「著作権を譲渡」だけでは翻案権等が**留保されたと推定**される（61条2項）。改修や派生開発の段階で判明しても遅い | p.247 |
| **著作者人格権の不行使特約** | 人格権は契約でも移転しない（59条）。特約がなければ相手は行使できる | p.247 |
| **退職後の競業避止・秘密保持** | 入社時に定めていないと、**揉めた退職者からは誓約書を取れない** | p.363–364 |
| **サイニングボーナスの支払い方** | 一括で払うと返還を求められない可能性が高い。**分割・後払いは設計時にしか選べない** | p.382–383 |
| **ライセンスの競業禁止条項** | IPO時の解消には**相手方の確認書**が要る。自社だけでは片付かない | p.256 |

### 【C】一度やってしまうと戻せない

| 論点 | 戻らないもの | 出典 |
|---|---|---|
| **従業員に株式を渡す** | 退職しても**一方的に権利を消滅させられず、株主として残り続ける**。会社が買い取ろうにも自己株式取得は分配可能額の財源規制があり、**違反すれば刑事罰**（会社法963条5項1号） | p.182 |
| **取締役会の過半数を失う** | 株主総会の招集に取締役会決議が要るため**すぐには戻せない**。解任には「正当な理由」が要り、なければ損害賠償請求権が発生（会社法339条2項） | p.109–110 |
| **累積型の優先配当を受け入れる** | 未払額が年度ごとに累積し、**IPOの支障になりうる**。累積した事実は消せない | p.153 |
| **事前承諾手続を形骸化させる** | 黙認状態が続くと、いざというとき**黙示の承諾・権利濫用**を認定されやすくなる。運用の履歴は遡って作れない | p.132 |
| **投資契約に内容を確認せずサインする** | 回収フェーズに入った投資家は「何か回収のネタがないかな」と表明保証違反を探す。**厳しい回収攻撃**にあう | p.104–105 |
| **NDAへのサイン** | 独占交渉権や競業禁止が紛れていても「聞いていない」は通らない。著者は「**一般的なNDAですから**と言われても必ず内容を確認してから」と | p.244 |
| **NDAなしでの情報開示** | 渡した情報は戻らない。**1人にでも秘密保持契約なしで開示すると非公知性を失う**可能性 | p.244–245, p.322 |
| **投稿物の権利帰属条項** | 「無償で全て譲渡」と書いて炎上すると、条項を直しても評判は戻らない | p.214 |
| **商標を取られる** | 名称を変えても**それまでの侵害の賠償義務は残る**。先使用権は周知性が要り、長期間使っているだけでは認められない | p.312 |
| **漏洩の最初の公表内容** | 過小に発表して後から拡大すると隠蔽体質を疑われる。訂正しても信頼は戻らない | p.289 |
| **公表しない判断** | ダスキン事件（大阪高判平18.6.9）では**取締役の善管注意義務違反**と認定された | p.289 注3 |
| **AI学習時の目的設定** | 学習が済んだ後に「享受目的ではなかった」と作り直せない。**設計時点で決まる** | p.334 |

### 【D】時間が経つと消える／間に合わない

| 論点 | 期限 | 出典 |
|---|---|---|
| **取得条項の発動と上場申請** | 発動には株主への**2週間前の通知または公告**。株券発行会社は原則**1カ月前までの株券提供の公告・通知**も要る。つまり上場申請の**1カ月以上前**に発動事由が発生していないと間に合わない | p.161 注1 |
| **外為法の事前届出の待期期間** | 届出後、**法令上30日（実務上2週間程度）**が満了しないと株式を取得できない。調達スケジュールが動く | p.176 |
| **誹謗中傷の発信者情報** | プロバイダのログ保存は**一般的に3カ月程度**。消えたら特定できない | p.297 |
| **未払い残業代** | 消滅時効5年（当分は経過措置で3年）。**過去分がIPO・M&Aで必ず出てくる** | p.348 |
| **売掛金の消滅時効** | 内容証明の催告で6カ月延ばせるが、完成すれば請求権自体が消える | p.299 |
| **個人データの利用目的** | 変更は「**相当の関連性**」の範囲内に縛られる。取得時の公表内容が後の利活用範囲を決める | p.222–223 |

## 2. 専門家に相談すべきタイミング

**「何を知っているか」より「いつ人を呼ぶか」**。以下は本書が明示的に専門家を勧めている箇所。

| タイミング | 誰に | 本書の記述 |
|---|---|---|
| **J-KISS等で投資家と契約交渉する段階** | 弁護士 | 「バリュエーションキャップ等の転換条件、契約条項についても確認することが肝要で、**必要に応じて専門家に相談することも検討しましょう**」[p.89] |
| **新株予約権付社債（CB）を発行するとき** | 弁護士 | 金商法の募集規制・会社法の現物出資規制を考慮した設計が要る。「上記の2つに比較すると**難易度が高く、専門家に相談したほうが安全**」[p.96] |
| **CBの転換条件の調整条項を読むとき** | 弁護士 | 「調整条項は難解であることが多く、**投資家側に有利な内容になっている場合もある**ため、不明な点があれば専門家のアドバイスを受けるのが安全」[p.170] |
| **ベンチャーデットでの調達を検討するとき** | 税理士・会計士 | 「適切な会計処理も重要であり…**税務・会計の専門家への相談も適時に行う必要がある**」[p.175] |
| **税制適格ストックオプションを設計するとき** | 弁護士・税理士 | 「きちんと税制上の優遇措置も満たす形で設計する場合は**専門家への相談をしたほうがよい**」[p.181] |
| **自己株式の取得（分配可能額の判定）** | 税務会計の専門家 | 「分配可能額は…会社にあるキャッシュの金額とイコールではないので、**税務会計の専門家に相談するのがよいでしょう**」[p.182 注2] |
| **サービス・商品名を決める段階** | 弁理士 | 「サービス・商品名決定の段階から、商標戦略を弁理士に積極的に相談したほうがよい」[p.314] |
| **みなし残業代・裁量労働制・管理監督者を設計するとき** | 社労士/弁護士 | 「社会保険労務士や弁護士等にも相談するなどして慎重に検討をしたほうが安全」[p.350] |
| **職務発明規程の制定と金額査定のプロセス設計** | 弁理士/弁護士 | 協議・開示・意見聴取の**プロセスが有効性を左右する**[p.318] |
| **個人データを外部から受け取る/外部に預けるスキーム** | 弁護士 | 提供元基準・匿名加工・仮名加工＋共同利用のどれを採るか [p.326–331]、外国への委託 [p.223–224] |
| **消費者向けサービスの免責条項** | 弁護士 | サルベージ条項が2023年施行の消費者契約法8条3項で無効に。**他社の規約を写すと古い法令のまま**[p.216] |
| **下請法の適用判断** | 弁護士 | 「スタートアップは資金調達により資本金が高くなっているケースが多く、**親事業者に該当しやすい**」[p.250] |
| **漏洩が発覚した直後** | 顧問弁護士 | Aに「顧問弁護士等とも相談のうえ」と明記 [p.287] |
| **解雇・退職勧奨を行う前** | 弁護士 | 無効なら給与と遅延損害金を遡って払う [p.361] |
| **事業の根幹に関わるライセンス契約** | 弁護士 | 解除条項・期間・競業禁止 [p.256–258] |
| **AI学習の目的が享受目的と併存しないかの評価** | 弁護士 | 「作風」の議論は判断が微妙 [p.334] |

### 相談前に自分で用意しておくもの

論点を持たずに相談すると、専門家の時間が状況把握で消える。**先に手元で揃えられるもの**。

- **自分がどちら側か**（開示者/受領者、委託者/受託者、ライセンサー/ライセンシー、供給者/代理店）
  ── 著者はNDAについて「**NDAをチェックする際には、まずはこの視点を思い出すように**」と [p.240]
- 契約書の**該当条項の現物**（下記3の自己チェックで印を付けた箇所）
- 投資契約なら: **現在の持株比率と取締役会の構成**（過半数をキープできるか [p.109]）、
  **既存の投資契約との整合**（各投資家が個別に契約を提示しているケースが多い [p.100]）
- 扱っている**個人データの件数**（1,000人を超えているか [p.288]）と**取得経路**
- 委託先が**フリーランス保護法の対象か**（従業員を使用しない個人／代表者以外に役員がなく従業員を使用しない法人 [p.373]）
- **資本金額**（下請法の適用判断に要る [p.250]）

## 3. 自分で判断してよい範囲

【評】本書の記述から導いた線引き。**これらは専門家を呼ぶ前に自分で確認できる。**

### 投資契約を受け取ったとき

**表明保証条項は、3つに分類するところまでは自分でできる** [p.105]。

| 分類 | 例 | 手当て |
|---|---|---|
| ①正しい | | そのまま |
| ②異なる事実がある | 実は商標権を他社に保有されている | **ただし書で例外を明記**（条項全体の削除を求めない） |
| ③自分ではわからない | 「訴訟を提起されるおそれがない」か否か | **「発行会社の知る限り」**を挿入 |

**投資家から「知り得る限り」への修正を求められたら、それは別物。** 「合理的に調査すれば
分かった」事項まで保証させる意味で、調査不足の落ち度があれば免責されない [p.107]。

**必ず確認する項目**

- **株式買取条項の請求対象に経営者個人が入っているか**（2022年3月の公取委・経産省の指針が
  「個人を除いていくことが競争政策上望ましい」としている [p.140]。交渉材料になる）
- **ドラッグ・アロング・ライトの目的はどちらか** — ①少数株主向けなら経営陣にも味方。
  ②経営陣向けなら発動要件に「時期」と「金額」を入れる [p.115, p.119]
- **取締役の派遣を受け入れた場合、取締役会の過半数をキープできるか** [p.109]。
  受け入れる／断るの二択ではなく、**オブザーバー＋情報請求権**という中間解がある [p.108–109]
- **新株等の優先引受権からSO発行が除外されているか** [p.135]
- **拒否権が「自分（投資家）だけのもの」か「種類株主総会の決議事項」か** — 後者だと
  同じ種類の株主全員が1株1議決権を持ち、その投資家単独では発動できない [p.150]

### 優先株式の条件が相場から外れていないか

本書が相場を明示している数少ない箇所。**照らし合わせるだけなら自分でできる** [p.156, p.158–159]。

| 項目 | 実務の相場 | 外れているときに聞くこと |
|---|---|---|
| 優先的残余財産分配 | **払込金額の1倍・参加型**（1.5倍もあり） | X倍が大きい理由は何か／非参加型の選択肢はあるか |
| 希薄化防止 | **加重平均方式**が一般的 | フルラチェットである理由は何か |
| 加重平均の計算基礎 | ブロードベースのほうが創業者に有利 | ナローベースになっていないか |
| 累積未払配当金の優先分配額への加算 | **「稀」** | 累積型にする目的は何か（配当ではなくExit時の取り分の話 [p.153]） |

### J-KISSのひな型を使うとき

著者は「**ひな型だからといってその内容を十分に把握せず、採用することはリスクが伴います**」と
明言したうえで、具体的に挙げている [p.94]。

- **M&Aを条件に一定の転換価額で転換可能**とされている
- **M&Aを条件に一定金額（例：投資金額の2倍）で会社が買取可能**とされている
- **表明保証条項**（QIV-4参照）、**最恵待遇条項**、**優先引受権**が規定されている
- **J-KISS1.xと2.0の混在**に注意。併用で**転換価額が算定不要になってしまうケースがある** [p.94 注6]

### 契約書を受け取ったとき（一般）

**まず「自分はどちら側か」を確認する。** 同じ条項でも立場が逆なら有利不利が反転する。

そのうえで、著者が示す修正テクニックのうち**②③④は機械的に適用できる** [p.236–237]。

| # | 直し方 |
|---|---|
| ② | 「防止**しなければならない**」→「防止**するよう努め**なければならない」（逆に相手にやってもらう事項は語尾を強くする） |
| ③ | 「甲の指示に従う」→「甲の**合理的な**指示に従う」 |
| ④ | 「**乙**は」→「**甲および乙**は」、「**甲**の秘密情報」→「**相手方**の秘密情報」 |

著者は④について「**汎用性がありますので、是非使ってみてください**」[p.237]。

- NDA: **目的外使用の禁止**があるか（秘密保持だけだと、協業目的で渡した情報を相手の独自開発に使われても違反にならない [p.242]）
- NDA: 独占交渉権・競業禁止が紛れていないか（**条項の表題ではなく本文を読む** [p.244]）
- 業務委託: **著作権法27条・28条**と**著作者人格権の不行使**が書かれているか [p.247]
- 全般: **競業禁止規定**と**任意解除規定**（著者が「特にリスクが大きい」とする2つ [p.233–234]）

### 自社のサービスについて

- 同意画面が[p.218]の「適切な事例」の形か（規約を表示したうえで同意ボタン。**掲載しているだけでは効かない** [p.217]）
- 規約ページへのリンクが**直接飛ぶ**か、リンク切れがないか [p.219]
- **同意ログとバージョン管理**を取っているか [p.219]
- プライバシーポリシーの利用目的が「事業活動のため」のような抽象語で終わっていないか [p.223]
- 禁止事項に**ペナルティが対で**書かれているか [p.210]
- 特許庁の商標検索サイトで**類似商標の有無**を見る（著者も「一般の方でも…おおよそのチェックをすることが可能」[p.312]）

### 社内について

- 入社時の**誓約書**に⒤知財帰属 ⒤⒤秘密保持 ⒤⒤⒤反社不該当 ⒤ⓥ競業避止 ⓥ勧誘禁止 が入っているか [p.345]
- **株式を渡す相手を絞れているか**。著者は「原則としてストックオプション、例外的に
  創業メンバーとほぼ同様の地位を占める幹部候補のみ株式」[p.180]。株式を渡すなら
  **創業株主間契約を必ず締結する** [p.183]
- SOの発行要項に**「退職したら権利を無償で会社が取得できる」**が入っているか [p.183]
- 労働時間を**客観的な記録**（PCログ等）で把握しているか。自己申告制に頼っていないか [p.348–349]
- 社内の情報に**アクセス制限と「秘密」表示**があるか [p.321]
- ハラスメントの**相談窓口を定めて周知**しているか [p.371]
- **漏洩時の初動手順を紙に書いてあるか**（誰が調査を始め、誰が報告フォームを開くか）
- 投資契約の**事前承諾手続を実際に回しているか**。形骸化すると、いざというとき
  **黙示の承諾・権利濫用**を認定されやすくなる [p.132]

### フリーランスに委託するとき

- 契約書・発注書のひな型に**8項目**が網羅されているか [p.374]
- 支払期日が**受領日から60日以内**か（検査完了時点ではない [p.375]）
- 6カ月以上の契約なら**30日前予告**の条項があるか [p.378]
- 契約不適合責任の期間が**1年を超えていない**か [p.376]
- **偽装請負のチェックリスト**を作る（判断基準は [p.379] にある。著者も推奨）

[scan p.0010]

## 5. 交渉の型 —「ゼロか100か」にしない

【評】本書を通じて繰り返し現れる型なので、独立して立てる。
第IV章の2箇所で、**まったく違う条項に同じ解が出ている**。

| 場面 | ゼロ100の罠 | 著者の解 |
|---|---|---|
| **ドラッグ・アロング・ライト** [p.119] | 「入れるか否か」で争うと「**投資を受け入れるか否かという究極的な交渉**」になる | 経営陣が本当に困っているのは**「時期」と「金額」**。発動要件に織り込む（「〇年〇月〇日以降」「時価総額〇億円以上」） |
| **取得条項（IPO前の強制転換）** [p.161–162] | 入れないとIPO前に転換できない。入れると投資家は優先権喪失リスクを負う | **条項は入れたうえで戻せるようにする**。株主間契約で「一定期間内にIPOが達成されなければ元の優先株式に戻す」と定める |
| **表明保証で事実と違う点があった** [p.106] | 条項全体の削除を求める → **他の保証まで消えるので投資家は応じない** | **ただし書で例外事項だけを明記する** |
| **株式買取条項** [p.141–142] | 条項自体を外せないケースが多い | **発動事由を自分でコントロール可能な範囲に限定する**（是正期間、「重要な点」、「合理的な理由なく」） |

**使い方**: 受け入れがたい条項が来たら、「拒否する / 呑む」の前に
**「相手が本当に確保したいものは何か」→「それを満たしつつ自分のリスクを削る条件は何か」**
を1回挟む。本書の交渉論はこの一点に集約されている。

## 6. Patchin／VoC で未解決の論点

本書からは答えが出ない。**専門家に聞くべき筆頭**。

### データ・プライバシー（Patchin本体）

1. **アセスメントスコアは「要配慮個人情報」に当たるか。**
   本書の定義（人種・信条・社会的身分・病歴・犯罪の経歴等 [p.287 注1]）には直接該当しないように
   見えるが、**心理的特性が「信条」に接近しうるか**は判断できない。
   当たるなら**1件の漏洩でも報告義務**が生じる [p.288]。
2. **提供元基準が Patchin のデータフローにどう当たるか。**
   顧客企業（提供元）が誰のスコアか分かっている以上、提供先で氏名を持たなくても
   第三者提供に当たりうる [p.326]。ただし本書の設問は医療データで、要配慮個人情報という
   別の重さがある。**この差が結論を変えるかは本書からは判断できない。**
3. **利用目的をどこまで狭く書くか。**
   `docs/strategy_for_business.md` の「監視しない・評価に使わない」は利用目的を意図的に
   狭く書くことを含意する。一方で本書は「将来の変更可能性も考慮」と言う [p.223]。
   **この2つは緊張関係にある。**狭く書けば思想が守られるが、将来の展開が塞がる。
   **法律問題ではなく経営判断。**
4. **PoCの記録と労務管理の交差。**
   パワハラ指針の「個の侵害」に「**労働者を職場外でも継続的に監視すること**」が挙がっている
   [p.367]。`docs/poc_plan_voc.md` の対象は業務中の打ち合わせであり職場外ではないが、
   **論点として接続する**。本書は労務管理の文脈で書いており製品設計の文脈ではない。

### VoC（社内ベンチャー）— ガバナンスと人

5. **親会社から VoC に役員が入る場合、その人が VoC の情報を親会社に持ち帰る根拠は何か。**
   本書は投資家派遣の取締役について「取締役の職務として取得した情報を、一株主である
   自分の派遣元の投資家に**何でも開示できるものではなく**、開示する場合には、発行会社の
   了解を得る必要があります」[p.113] とし、対処として「投資契約でこの点の情報開示ができる旨を
   定めておくことも1つの方法」と言う。**VoC には投資契約がない。**
   善管注意義務の議論が出資関係のない親子間でも成り立つのかは本書からは判断できない。
6. **VoC の意思決定に親会社の稟議が何段階も挟まる構造は、p.132 の「事前承諾事項を
   細かくしすぎるリスク」と同じ問題を抱えていないか。** 特に**運用が形骸化した場合**に
   黙示の承諾を認定されやすくなる点。本書は投資契約の文脈で書いており親子会社間ではない。
7. **VoC の職務発明は誰のものか。** 親会社の職務発明規程が適用される可能性。
   本書は自社で規程を作る前提で書かれており [p.315–318]、この分岐に触れていない。
8. **下請法の資本金判定は親会社基準か。** 該当すると支払条件が法的に縛られる [p.250]。
9. **VoC の人員に SO を出せるか。** 出向者や親会社従業員が対象の場合、税制適格の
   「取締役または従業員」要件をどう満たすか。本書は自社雇用が前提。
10. **親会社が「外国投資家」に該当する可能性はないか。** 日本法人でも外国の非居住者・
    外国法人の議決権比率が50%以上なら該当しうる [p.175]。**役員派遣も対内直接投資等に
    該当する**[p.177] ので、資本関係だけでなく人の派遣でも問題になる。
11. **VoC の「Exit」に相当するものは何か。** 第IV章の全条項は Exit の確保を前提に
    組まれている。社内ベンチャーには IPO も M&A もない。
    **この章の構造がどこまで転用できるか**は本書からは判断できない。

## 7. この文書の限界

【評】

- **5章分しか読んでいない**（冒頭の射程を参照）。設立時の設計、会社法の基本、
  M&Aの実行、上場審査の論点は入っていない
- **第IV章前半（印刷 p.85–104）はL1カードを経ていない。** 補正テキストからの直接引用のため、
  他の範囲より抽出の網羅性が落ちる可能性がある
- 出典はすべて**第2版（2025年4月時点）**。この分野は改正が速い。特に
  フリーランス保護法（2024年11月施行）は運用実績が浅く、資金決済法・景品表示法も改正が続く
- **投資契約の記述は「相場」が伏字のものが多い。** 「〇%」「〇億円」「X倍」の具体的な水準は
  優先残余財産分配（1倍）以外ほぼ示されていない。**交渉の相場観は別途要る**
- **著者は AZX（起業家側の法律事務所）**。投資家側の視点も併記されているが、
  「フェア」の線引きに立場が反映されている可能性は割り引く
- 株式買取条項の「個人を外すケースが増えている」は**著者の「印象」**が根拠 [p.141]。
  統計や事例の集計ではない
- **進行中の論点がある。** 優先的残余財産分配の非参加型への移行について著者自身が
  「今後の実務の動向に注目されます」[p.156] と書いている。この記述はすぐ古くなりうる
- 個人情報漏洩の賠償相場は**平成18年・19年の裁判例**に依拠 [p.290–291]。
  個人情報への社会的感度は当時と変わっている
- **「誰がやるか」は書かれていない。** 法務部のない組織で、漏洩発覚から3〜5日以内に
  誰が動くのかは自分たちで決める必要がある
- 本書はAI学習について**文化審議会の「考え方」（令和6年3月15日）に依拠**しており [p.332 注1]、
  裁判例による確立ではない
