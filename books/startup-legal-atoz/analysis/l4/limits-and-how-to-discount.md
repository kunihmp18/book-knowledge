# L4 — 本書の限界と、引くときの割り引き方

## この層は何のためにあるか

L0〜L2 は「本書が何を言っているか」を扱う。この層は **「その記述をどれだけ信じてよいか」** を扱う。

本書は良い本で、ここに書くのは欠陥の告発ではない。**どの記述も同じ強さではない**、という
当たり前のことを明示するための層である。実務では、割り引き方を知らずに引くほうが危ない。

使い方は1つ：**本書から何かを引いたら、§1 の6段階のどれに当たるかを確認する。**
【D】以下なら、それは「本書がそう書いていた」以上のことは意味しない。

## 1. 根拠の強さ — 本書の記述は6段階ある

本書は Q&A 形式で、条文の話も著者の感想も**同じ「解説」の見た目**で並ぶ。
これが本書の最大の読みにくさで、意識的に分けないと混ざる。

| | 段階 | 本書での書かれ方 | 割り引き方 | 例 |
|---|---|---|---|---|
| **A** | 条文 | 「会社法○条」「法○条○項」 | 割り引き不要。ただし**改正の時点だけ確認** | 税制適格SOの要件 [p.185]、分配可能額の算定（会社法461条2項）[p.74, p.82] |
| **B** | 裁判例 | 「裁判例では」「実例にあるとおり」 | **事案の射程と年代**を確認。相場は変わる | 個人情報漏洩の賠償相場（平成18・19年の裁判例）[p.290–291] |
| **C** | 行政の指針 | 「指針には」「考え方では」 | **法的拘束力の程度が違う。**著者自身が注記する場合もある | パワハラ指針の「個の侵害」[p.367]、文化審議会「AIと著作権に関する考え方」（令和6年3月15日）[p.332 注1] |
| **D** | 実務慣行 | 「〜が一般的です」「〜のケースが通常です」 | **相手次第で変わる。**交渉材料にはなるが根拠にはならない | 希薄化防止は加重平均方式が一般的 [p.159]、みなし清算の対価分配は優先残余財産分配と同様 [p.126] |
| **E** | 著者の印象 | 「〜という印象です」「〜が増えてきている印象です」 | **集計ではない。**当たっているかもしれないが、検証されていない | 株式買取条項から個人を外す妥結が「増えてきている印象」[p.141]、J-KISS が「特に多く使用されている印象」[p.89] |
| **F** | 著者の価値判断 | 「〜すべきでしょう」「〜が望ましい」 | **立場が入る。**§2 と併せて読む | ベスティングへの否定的評価 [p.33–34]、「特別な理由がない限り発起設立」[p.46] |

### この分類が実際に効く例

**株式買取条項**（第IV章）は、本書の中でも段階が入り混じっている典型：

- 「日本特有のもので、米国の投資契約には見られない」[p.140] ── **事実の指摘（A に近い）**
- 公正取引委員会・経済産業省「スタートアップとの事業連携及びスタートアップへの出資に関する指針」
  （2022年3月31日）に「請求対象から経営株主等の個人を除いていくことが、競争政策上望ましい」
  との記載がある [p.140, p.141 注1] ── **C（行政の指針）**
- しかも著者自身が「**あくまで競争政策について言及したものであり、個別の投資案件における
  契約条件の適法性に言及したものではありません**」と限定している [p.141]
- 「妥結するケースも増えてきている**印象です**」[p.141] ── **E（著者の印象）**

つまり **「指針があるから個人保証は外せる」とは本書は一言も言っていない。**
交渉のときに指針を持ち出すのは有効だが、**相手が応じる義務はない**。
ここを混ぜて読むと、交渉の場で梯子を外される。

## 2. 著者の立場 — AZX は起業家側の法律事務所である

本書は投資家側の視点も丁寧に併記しており、その点は誠実である。
ただし**「フェアな線引き」がどこかという判断には、立場が反映されうる**。

確認できる範囲での現れ方：

- **本文中に事務所自身のサービス紹介が複数箇所ある。**
  ビジネスモデルの無料審査 [p.7 注1]、「当AZX総合法律事務所をはじめ…専門家に相談してみるのもよい」[p.11]、
  投資契約等のひな型を事務所サイトで無償公開 [p.207 注1]
- **ベスティングへの否定的評価** [p.33–34]。海外では一般的と認めたうえで4つの理由で退けている。
  日本の実務を前提とした判断であり、**海外人材を採る場合の実務とのギャップは埋まっていない**
- **株式買取条項の議論**は、起業家個人を買取義務から外す方向を支持する構成になっている [p.140–141]。
  結論の当否とは別に、**投資家側の本を1冊読めば別の書きぶりになりうる**と想定しておく

**割り引き方**：本書が「フェアではない」「起業家に不利」と評価している条項については、
**「相手はそう思っていない可能性がある」**を常に足す。事実の記述（何がどう効くか）は
立場に依存しないので、そこは割り引かなくてよい。

## 3. 本書が「書かない」と宣言した箇所

著者が明示的に踏み込まないと書いている領域。**検索でそれらしい文章がヒットしても、
そこに答えはない。**

| 論点 | 本書の書き方 | 出典 |
|---|---|---|
| 難しい論点・テクニカルな内容 全般 | 「あえて踏み込んでいないところもあります」「具体的な事案に活用する際には、是非弁護士等の専門家のアドバイスも受けていただければ幸いです」 | はしがき（scan p.0010） |
| 分配可能額の計算方法 | 「詳細は割愛しますが」 | p.74, p.82 |
| 自己株式取得のみなし配当課税の計算 | 割愛 | p.83 |
| J-KISS 1.x と 2.0 の混在 | 「やや複雑であるため詳細な説明は割愛しますが、**転換価額が算定不要となってしまうケースがある**」 | p.94 注6 |
| 税制適格の詳細（QV-2 の段階） | 「ここでは割愛しますが」→ QV-3 で回収 | p.185 |
| 新株予約権の公正時価発行 | 「ここでは詳細は割愛します」 | p.190 |
| 役員報酬の金額算定の考え方 | 「金額算定の考え方はいろいろ議論があり、そこは今回割愛します」 | p.317 |
| 指名委員会等設置会社 | スタートアップでの採用例が多くないため「説明は割愛」 | p.418 注2 |
| 募集設立の手続 | 「特別な理由がない限り発起設立としたほうがよい」として詳細を割愛 | p.46 |

**J-KISS 1.x/2.0 の混在は特に注意。** 「転換価額が算定不要になるケースがある」という
**結果だけ書いて中身を書いていない**。J-KISS を2回以上使うなら、本書では判断できない。

## 4. 数字が伏字 — 本書の最大の穴

本書の相場感は、**具体的な数字がほとんど「〇%」「〇億円」で伏せられている**。
これは第IV章（資金調達）と第IX章（M&A）で特に顕著で、L1 の複数のカードが独立に指摘している。

### 示されていないもの（＝別途調べる必要があるもの）

- 資金調達の**バリュエーションキャップの水準**、**ディスカウントレート**
- **ストックオプション・プールの割合**（「○％とする」と伏字 [p.204]）
- **キーマンクローズの期間**（「〇年間」）
- **ドラッグ・アロング・ライトの発動金額基準**
- M&A の**時価総額基準**（「〇億円以上」）
- **持株比率の実務感覚** ── 本書は QI-3 で「実務感覚がわからない」ことを失敗の原因に挙げながら [p.10]、
  **その実務感覚の中身は示していない**

### 示されているもの

L5 §6 に20件まとめてある。**本書から数字を引けるのはそこだけ**と思ってよい。

**割り引き方**：本書は「何を決めるか」の地図であって、「いくらが妥当か」の相場表ではない。
数字が要る場面では、**本書を根拠にしてはいけない。**

## 5. 時点 — 何がいつ古くなるか

基準時は**第2版・2025年4月**。全ファイルの `as_of: 2025-04` はこのため。
ただし**中身によって賞味期限が違う**。

| 賞味期限 | 対象 | 理由 |
|---|---|---|
| **すでに古くなっている可能性** | 個人情報漏洩の賠償相場 [p.290–291] | 平成18・19年の裁判例に依拠。社会的感度が当時と違う |
| **短い（1〜2年）** | 税制適格SOの要件、資金決済法、景品表示法、個人情報保護法 | 改正が頻繁。本書内だけで2023年5月国税庁Q&A・2023年4月改正・2024年4月改正・2024年9月産競法特例が言及されている |
| **短い（運用が固まっていない）** | フリーランス保護法（2024年11月施行）、代表取締役住所非表示措置（2024年10月開始）、情報流通プラットフォーム対処法 | 施行が新しく、**実際にどう運用されるかの蓄積がまだない** |
| **流動的（著者自身がそう書いている）** | 優先的残余財産分配の非参加型への移行 [p.156]、IPO審査のスタンス [p.411, p.413] | 「今後の実務の動向に注目されます」「その時々の証券取引所のスタンスによっても微妙に変化」 |
| **不安定（法解釈が確立していない）** | AI学習と著作権 [p.332 注1] | 文化審議会の「考え方」（令和6年3月15日）に依拠。**裁判例による確立ではない**。著者も「解釈される可能性もある」と留保付き |
| **長い（構造の話）** | 株式を出す／戻すの非対称、DDで見られる項目、契約に書かなければ相手の同意次第という構造 | 制度が変わっても効き方が変わらない |
| **注意：ひな型には世代がある** | 総数引受の承認要件（平成27年改正）[p.71]、J-KISS 1.x / 2.0 [p.94 注6] | 著者自身が**改正前のサンプルが出回っている可能性**を警告している |

**「ひな型は使ってよい。ただしいつのものか確認せよ」**が本書から引き出せる一般則。
2箇所で独立に警告されている。

## 7. 「誰がやるか」が書かれていない

本書は**「何をするか」は書くが、「誰が」は書かない**。
法務部がある会社を暗黙に想定した箇所がある。

- **漏洩対応**：報告対象事態を知ったら「速やかに（概ね発覚日から3〜5日以内）」速報 [p.288]、
  原則として発覚日から30日以内に確報 [p.289]。
  ── しかし**法務部のない組織で誰が動くのか**は書かれていない
- **通報窓口・相談窓口**：ハラスメント、内部通報とも「設置する」で終わる。
  ── **少人数でどう作るか、経営者本人が当事者・被通報者の場合どうするか**には踏み込んでいない。
  第VIII章・第X章の**両方で同じ穴**が空いている
- **賃金・評価制度**：何が必要かは書かれているが、**どう作るかは書かれていない**
- **利用規約の運用**：作り方に寄っており、**削除判断の実務、通報対応**は薄い
- **契約交渉**：「まずは削除を交渉すべき」[p.233] とは言うが、
  **相手が応じない場合の落としどころの探り方**は薄い

**割り引き方**：本書のチェックリストは**そのままでは実行に移せない**。
「誰が・いつまでに」を自分たちで埋めて初めて運用になる。

## 8. 前提が違う読者 — 社内ベンチャー／VoC への外挿限界

**本書は「独立資本のスタートアップ」を前提に書かれている。**
社内ベンチャーに読み替えるとき、次の箇所は前提が崩れる。L1 の12枚が独立に同じ指摘をしている。

| 本書の前提 | VoC で崩れる点 |
|---|---|
| 株式がある | 株主間契約・種類株式・SO の議論が**直接は当てはまらない**。ただし「一度与えたものを戻すのは重い」という構造は残る |
| 出口（IPO/M&A）がある | 第IV章の全条項は Exit 確保を前提に組まれている。**社内ベンチャーには出口がない**。ただし DD と IPO審査のチェック項目は「普段やっておくべきこと」として意味を持つ |
| 自社が委託者・雇用主 | 外部エンジニアへの委託主体、就業規則、職務発明規程が**親会社のものである可能性**。知財の帰属先が変わる |
| 意思決定は取締役（会） | **親会社の稟議規程が上位にある。**「何が正式な決定か」の定義が違う |
| 投資契約がある | 派遣役員の情報持ち帰りを規律する根拠が**VoC には存在しない**。本書の対処は「投資契約で定める」[p.113] |
| 利用者は外部の顧客 | ユーザーが従業員なら、**利用規約ではなく社内規程・労働契約の系統**になりうる。かつ**雇用関係下の同意が「自由な同意」と言えるか**は本書の射程外 |
| 資本金は自社のもの | **下請法の資本金判定が親会社基準になる可能性**[p.250]。該当すると支払条件が法的に縛られる。なお**フリーランス保護法には資本金要件がない** [p.373] ので、こちらは VoC 名義でも適用される |

**割り引き方**：VoC の文脈で本書を引くときは、**「この記述はどの前提に乗っているか」を先に確認する**。
上の7行のどれかに触れていたら、そのまま使えない。

## 10. この層の限界

- **本書と対照するための他の本を読んでいない。** 投資家側の書籍、実務書、判例集と
  突き合わせれば「著者の立場」の影響はもっと具体的に測れる。現状は**本書の内部だけで
  検出できた歪み**にとどまる
- **§1 の段階分けは、本書の文末表現を手がかりにした機械的な分類**であって、
  著者の意図と一致する保証はない。「一般的です」と書かれていても、
  実質は条文由来の話である場合がある
- **数字が伏字である理由を本書は説明していない。** 出版物として相場を書けない事情
  （すぐ古くなる、事務所の守秘、案件差が大きい）が推測できるだけで、確認はしていない
- **索引を対象外にした**（L0 で `skipped`）ため、
  **「著者が索引項目として何を重要と考えたか」という重み付けの資料は失われている**
- この文書自体が **2025年4月時点の本を、2026年に読んで書いたもの**。
  §5 の「短い」に分類した項目は、**この文書を書いている時点ですでに動いている可能性がある**
